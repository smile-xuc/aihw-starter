端到端实时语音：模型直连硬件，中间只留一层宿主

Get started

怎么用这个仓库

四类读者，四条最短路径。

Solution vendor

判断 → 搭建 → 算账

先读 01-business.md 判断要不要做，再读 02-solution.md 看架构，最后 03-cost.md 算账。

Brand owner

看全景 → 选方向

先看本页全品类总览，锁定方向后进入对应品类的 01-business.md。

Developer

跑 demo → 改造

进入 demo/ 跑通示例，再改造成自家产品；实时语音直接看 Runtime Host 骨架。

Researcher

看生态全集

$ cd aihw-starter
# 按品类看：商业 → 方案 → 算账

$ open solutions/by-solution/01-qwen/omni-realtime/
