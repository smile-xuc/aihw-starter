怎么用这个仓库

不同角色的最快入口

方案商

判断 → 搭建 → 算账

先读品类 01-business.md 判断要不要做，再读 02-solution.md 看架构，最后读 03-cost.md 算账。

品牌商

看全景 → 选方向

先看本页全品类总览，锁定方向后进入对应 solution 的 01-business.md。

开发者

跑 demo → 改造

进入 solutions/0X-xxx/demo/ 跑通示例 → 改造成自家产品。
