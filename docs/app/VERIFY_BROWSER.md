### 真实接口与设备

1. 用对应地域、已有模型权限的百炼 Key，在“我的”填写凭证。先使用会话存储并设置账号侧预算或额度；不要把 Key 写入截图、轨迹、Issue 或本文件。
2. 从首页进入两个精选体验，选择素材，去填写凭证后保存并返回。核对问题、文件与玩法仍在，且没有自动发起计费请求。
3. 先用内置样本，再用允许发送给百炼的个人素材运行。原图/录音只在本机预览，确认开始真跑后由浏览器直发官方接入点。检查跨域预检、请求地址、响应状态及模型权限。核对流式文字、声音播放、纪要、逐字稿和返回的用量；北京有 HTTP 语音合成，新加坡只返回文字。
4. 测试错误 Key（401）、权限不足（403）、断网、停止和重试。再试空/损坏/超限素材，确认在计费请求前被拒绝。静音或空响应须有明确反馈。会议纪要失败时检查是否保留了已完成的逐字稿。
5. 用 2–3 分钟密集讲话录音核对末句与 `usage.output_tokens`，同时用包含尾部静音的录音区分“疑似截断”与真正缺失内容。页面的提示是启发式判断，必须人工核对。
6. 复制结果、下载结果文件、导出轨迹；从本机历史再次打开。刷新页面后文本仍可打开；关闭浏览器或更换设备后不会保留原素材，临时语音地址不写入历史。检查历史和导出记录不含 Key、鉴权头、图片/录音二进制和签名音频地址。
7. 在桌面浏览器、实际 iPhone Safari 和实际 Android Chrome 分别重复选择素材、配置返回、运行/停止、复制/下载、历史打开及 PWA 离线回放。390 px 的自动化视口检查只说明布局，不算手机实机验证。

## 统计口径

- **文字首包**：本轮模型处理开始至收到第一个文字增量；会议场景包括前置同步转写。兼容轨迹字段 `first_token_ms` 使用此口径。
- **音频首包**：仅在真正接收到流式音频首包时记录；本轮 HTTP 整段合成没有此指标，显示不可用。
- **整段语音地址就绪**：收到合成接口返回的音频 URL。它不代表音频已下载、解码或开始播放。
- **总耗时**：场景处理开始至本轮结束，包含网络和合成；转写耗时单列。这些是浏览器时间，不能与设备端首音频延迟直接比较。
- **按用量计算**：接口返回完整用量 × 仓库价格表，是计算值，不是最终账单。缺失必要用量时显示费用未知；时长/字符推导的费用必须标估算。未调用云端的回放使用 mock 示意成本。
