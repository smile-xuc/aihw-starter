# 体验广场界面设计

2026-10-04。本轮保留体验、品类、硬件、成本和设置的既有路径，更新视觉层次、响应式布局和操作反馈。

## 参考与取舍

实际浏览了以下公开页面，没有登录产品工作区，也没有复制字体、图标或品牌素材：

| 参考 | 观察范围 | 应用于广场 |
|---|---|---|
| [Linear](https://linear.app/) | 官网展示的应用界面 | 左栏、工具栏和正文有明确层级；颜色用于选中与状态，避免所有信息都使用同样的重卡片 |
| [Raycast](https://www.raycast.com/) | 官网展示的启动器、结果列表 | 紧凑任务入口、清楚的主次信息与即时操作反馈 |
| [Vercel Geist](https://vercel.com/geist/introduction) | 实际可操作的公开设计系统，含明暗主题和搜索面板 | 中性色表面、细描边、统一线性图标、克制的组件尺寸和短过渡 |

广场继续使用本站资源与系统字体。本仓绘制线性 SVG 图标，精选照片来自原有公开样本，音频卡上的波形与笔记仅作内容类型预览。配色以 [官网首页](../index.html) 为依据：暖白底色、深灰文字与亮蓝主色，让官网与体验工作区保持同一品牌。保持浅色，不跟随系统切黑。

## 视觉与布局

- 页面、文字、分隔线和字体栈与官网一致；卡片使用纯白，次级表面使用中性浅灰。主操作、链接、当前导航、选中状态、照片和录音的装饰统一使用官网亮蓝；按钮悬停变为官网深蓝，保留白字对比度。移除整页青色调与录音卡的大块薄荷装饰，阴影和弹层遮罩也回归中性。
- 绿色只用于成功与端侧语义标签；警告用浅杏、错误用浅珊瑚，均配文字。不同任务以图标、标题和内容预览区分，不再各自使用一套主色。
- 通用卡片圆角 12–16px，按钮 8–10px；常驻阴影减轻。可点击卡片有进入箭头和交互反馈，普通信息卡保持稳定。
- 手机精选体验为单列，保留可触达的底导航。600px 起允许双列，768px 起使用紧凑左导航，1100px 起展开完整侧栏及体验／成本两栏，1280px 起品类三列。
- 手机输入框使用 16px 字号，避免聚焦时被系统放大。设置表单在宽屏限制正文宽度；长文本、结果与表格继续允许换行或独立滚动。
- 体验页始终显示参考实现与验证状态标签，较长的许可说明可展开查看，让素材与结果更靠近主要操作。
- 始终使用浅色：不随系统切黑，旧 `dark/system` 偏好仅规范化外观键，不改凭证或历史。HTML 从首帧声明浅色，浏览器/PWA 顶栏同色；“我的”移除旧外观开关。保留旧主题函数导出，以兼容更新期间仍被缓存的模块。

| 用途 | 色值 |
|---|---|
| 外层／页面／卡片 | `#F0F1ED` / `#FAFAF8` / `#FFFFFF` |
| 次级表面／分隔线 | `#F0F1ED` / `#E5E7E1` |
| 正文／次要文字 | `#202322` / `#626B61` |
| 主按钮与链接／悬停／浅蓝选中 | `#345BE8` / `#2346C4` / `#EEF2FF` |
| 薄荷状态／文字 | `#E7F7F0` / `#236A53` |
| 警告背景／文字 | `#FFF4DF` / `#865320` |
| 错误背景／文字 | `#FFF0EE` / `#A63D37` |

主按钮白字对比度约 5.52:1，悬停后约 7.65:1；亮蓝文字在浅蓝选中背景上约 4.93:1，常用浅色表面的次要文字最低约 4.88:1。照片说明栏和 Toast 也使用浅色。页面与浏览器/PWA 顶栏均为官网暖白 `#FAFAF8`。

维护时以官网的 `--paper/--ink/--muted/--line/--soft/--blue/--blue-deep/--blue-soft` 为基准，对应广场的 `--bg/--fg/--muted/--line/--surface-low/--accent/--accent-hover/--accent-light`；`--accent-ink` 引用 `--accent`，避免链接再次漂移成另一套主色。

## 微交互

| 操作 | 反馈 |
|---|---|
| 鼠标经过任务卡 | 细边线加深、最多 2px 上移、箭头轻移；只对可悬停的精细指针启用 |
| 按下按钮／卡片 | 轻微压下，释放恢复；不阻挡点击 |
| 页面／结果出现 | 一次约 240ms 的淡入与 6px 位移，内容从首帧可见，无逐项等待 |
| 等待页面数据 | 180ms 后才显示顶部加载反馈，避免缓存页面闪烁；不展示虚构百分比，过期请求不覆盖当前状态 |
| 选择／拖入素材 | 本机格式与大小预检，再实际解码；拖入、核验、通过与错误都有可辨认反馈 |
| 输入问题 | 更新当前字符数；不会自动发请求 |
| 减少动态效果 | 停止 CSS 动画、过渡和平滑滚动，保留静态选中、加载与焦点提示 |

音频卡的波形仅在鼠标经过时响应两次；界面空闲时没有循环装饰动画。真正等待网络时的加载条在完成或切换页面后停止。

## 可访问性与回归

键盘可跳到主要内容，且不会改变应用路由。保留焦点轮廓、原生文件选择、拖放区的 focus-within 提示、状态播报、弹层 Escape 与焦点归还。关键动作不依赖 hover，触控端不会套用桌面卡片悬停效果。

`docs/tools/interaction-smoke.mjs` 检查动效、减少动态效果、触控／键盘、系统深色下的浅色界面、旧偏好与首屏、新布局、拖放、草稿和加载竞争；既有 APP、工作区与跨页回归继续检查真实使用路径和 SW v10 离线能力。浏览器尺寸模拟不替代物理 iPhone／Android 验收；模型结果与费用仍需按 [真实接口验收](VERIFY_BROWSER.md) 验证。
