# AIHW 功能广场 · 首页设计

2026-09-30 · v1 · 产品体验者优先

首页的目标是：先看到效果，找到想尝试的功能，再进入体验。延续项目官网的紫色品牌，采用浅色背景、场景卡片和紧凑的首屏内容。

## 首页结构

1. AIHW 品牌与体验说明入口。
2. 大标题「功能广场」与搜索。
3. 按项目真实硬件品类筛选，覆盖 9 类硬件。
4. 今日精选「给 AI 打电话」，对应眼镜 omni-realtime 示例。
5. 值得一试：实时同传、情绪动作联动、会议纪要、自然语言找回放。
6. 首次体验入口「一看即懂」。
7. 底部导航：广场、方案、收藏、我的。

所有功能卡片都来自源项目所列功能，体验弹层提供示例交互，链接到对应的仓库方案或 Demo。

## 双端适配

| 维度 | iOS 27 方向 | Android Material 3 方向 |
| --- | --- | --- |
| 字体 | 系统字体、32 px 大标题 | Roboto 优先、30 px 标题 |
| 搜索 | 灰色圆角搜索输入 | 色调表面、胶囊搜索输入 |
| 分类 | 胶囊选中状态 | 带勾选状态的 Filter chips |
| 内容 | 实色内容卡片 | 色调 surface、较大圆角 |
| 导航 | 悬浮半透明玻璃、克制描边 | 80 dp 方向的底栏与胶囊选中指示 |
| 点击区域 | 44 pt 方向 | 48 dp 方向 |
| 外观 | 浅色与深色 | 浅色与深色 |

页面使用 CSS 像素表达原型尺寸。正式原生实现时，分别用 SwiftUI/UIKit 和 Compose 的系统组件、pt/dp/sp、安全区与 Dynamic Type；Web 原型展示视觉与交互方向，无法复现系统级 Liquid Glass 的光学效果。

玻璃只用于 iOS 导航层；内容卡片保持实色。原型支持键盘焦点、弹层焦点约束、Escape 关闭、减少动态效果偏好与屏幕阅读标签。

## 可操作内容与范围

- 双端对照、单端查看、深浅色切换。
- 搜索、分类筛选、空结果状态。
- 收藏与取消收藏，本地保存，在两端预览间同步。
- 体验弹层：示例输入、模拟响应、样例输出、再次体验和方案链接。
- 桌宠弹层支持不同情绪输入与回应样例。
- 收藏页、全部方案页和本次体验记录为辅助预览。

体验输出为本地预设样例；未调用 AI API，也未开启麦克风、摄像头或控制硬件。正式 APP 接入属于下一阶段。

## 使用

直接打开 `index.html` 可以离线查看，图像和图标已内嵌。需要服务器预览时，可从当前项目根目录运行：

```sh
python3 -m http.server 4311 --directory outputs/designs
```

在浏览器访问 `http://localhost:4311/aihw-square/index.html`。

手机宽度下自动切换为全屏 APP。使用 `?platform=ios` 或 `?platform=android` 可选择平台。
