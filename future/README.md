> 本目录收录后续计划纳入的品类与方向。当前所列方向尚处于早期或待观察阶段，公开案例与商业化路径不如 `solutions/` 中已收录的 6 类成熟。

## 现有文档

- [`lobster.md`](./lobster.md)：具身智能 / 桌面服务机器人方向（含「AI 龙虾」类玩法）
- [`watch.md`](./watch.md)：智能手表 / 健康可穿戴 AI 化方向

## 路线说明

`future/` 目录的内容晋升到 `solutions/` 的判定标准：

1. **市场量级**：年出货量稳定在百万级以上
2. **公开商业化样本**：已有公开可查、商业模式清晰的代表性产品
3. **架构通用化**：可抽象出 ≥1 套通用接入架构，不再是「每家完全不同」
4. **运营数据可信源**：可以引用公开披露的销量 / 渗透率 / 订阅数据

满足上述条件后，对应方向会从 `future/` 迁移到 `solutions/0X-xxx/` 目录，并补齐 `README + 01-business + 02-solution + 03-cost + 04-cases + 05-faq + demo/` 完整结构。

## 贡献新方向

如果你认为某个方向应当纳入 `future/`，欢迎提 PR 在本目录新增 `<方向>.md` 文件。文件结构建议参考 `lobster.md`：

- 现状概览
- 代表性产品 / 项目（公开来源）
- 主要技术挑战
- 商业化探索路径
- 待观察信号

详见根目录 [`CONTRIBUTING.md`](../CONTRIBUTING.md)。
