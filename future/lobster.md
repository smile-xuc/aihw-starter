# 具身智能 / 桌面服务机器人（lobster）

> 「lobster」一词来自社区俗称「AI 龙虾」——指代以多自由度机械臂、多传感器协同为核心，落地在桌面/家庭/小型商用场景的具身智能终端。本方向尚处早期阶段，暂收入 `future/`。

---

## 现状概览

具身智能（Embodied AI）在 2024–2026 年间从实验室走向消费/商用边缘，主要体现为：

- **本体侧**：仿人形态、四足、桌面机械臂、轮式底盘 + 机械臂等多形态并行
- **模型侧**：VLA（Vision-Language-Action）大模型、世界模型、端云协同推理
- **场景侧**：科研/教学开发套件 → 桌面陪伴/工具型机器人 → 家庭/商用试点

相比已经形成清晰订阅样板的 IPC、已经有量级出货的 AI 玩具，具身智能尚未出现「年出货百万级 + 商业模式跑通」的代表性产品，因此暂列入 `future/`。

## 代表性产品与项目（公开来源）

### 桌面/陪伴形态

- **Vector / Cozmo**（Anki / Digital Dream Labs）：早期桌面机器人代表
- **LOOI Robot**：将手机变身为桌面机器人的形态
- **Sesame**（开源）：桌面陪伴机器人项目

### 仿人/四足

- **Unitree G1 / H1**：四足与人形开源平台
- **小米 CyberOne / CyberDog**：大厂消费级展示
- **Boston Dynamics Spot**：商用四足标杆（高端定价）

### 教学/开发套件

- **LeRobot**（Hugging Face 开源）：低成本机械臂学习平台
- **Reachy / Pollen Robotics**：开源人形上半身

### 国内具身智能新势力

- **银河通用 / 智元机器人 / 宇树 / 逐迹动力 等**：以人形/四足为主的本体厂
- **桌面机械臂方向**：多家初创围绕「家庭/办公桌面助手」展开探索

> 以上列表仅作公开信号收集，不代表已商业化成熟。

## 主要技术挑战

1. **VLA 端云协同**：动作生成对延迟敏感（&lt;100ms 级），云端推理难以满足，端侧又难承载完整 VLA
2. **数据采集成本高**：每个新场景需要大量遥操作数据，泛化能力仍是瓶颈
3. **本体硬件成本**：多自由度机械臂 + 多传感器导致 BOM 居高不下
4. **安全与可靠性**：消费场景对碰撞、跌落、误操作的容忍度极低
5. **能源**：续航与充电体验是消费化重要门槛

## 商业化探索路径

目前公开可见的探索方向（按可行性递减）：

1. **教育 / 创客 套件**：3000–10000 元价位，面向学校 / 创客 / AI 实验室，已经形成稳定细分市场
2. **桌面陪伴 + IP**：以 IP 形象 + 简单交互动作为卖点，订阅化路径与 AI 玩具相近
3. **小型商用服务**：餐饮迎宾、商场导览、博物馆讲解（B 端为主，C 端弱）
4. **家庭通用助手**：远期愿景，5 年内难落地

## 待观察信号

- VLA 端侧化（≤7B 参数 + 量化）能否支撑桌面机器人独立完成常见任务
- 是否出现 1000–3000 元价位、面向消费者的 AI 龙虾爆品
- 数据采集 / 仿真 工具链能否将单场景数据成本压到万元级以内
- 公开订阅化路径（按动作次数 / 按服务包）是否跑通

---

## 与 千问大模型 / 同类基础模型 的接入想象

目前阶段，具身智能本体厂与大模型的合作多为：

- 使用大模型完成 **任务规划 / 自然语言理解** 部分，动作生成由本体厂自己的 VLA 模型负责
- 使用大模型作为 **多模态感知** 入口（视觉问答、语义分割），辅助任务理解
- 使用大模型完成 **对话陪伴层**（嘴 / 表情 / 语气），与 AI 玩具形态共享技术栈
