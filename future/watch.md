# 智能手表 / 健康可穿戴 AI 化（watch）

> 智能手表与健康可穿戴是出货量极大的成熟品类，但在「AI 化深度」与「订阅商业化」上仍处早期。本方向暂收录在 `future/`，待出现明确通用接入架构后再考虑晋升至 `solutions/`。

---

## 现状概览

智能手表（含手环、戒指、贴片等可穿戴形态）市场成熟、年出货量稳定在亿级以上，主要参与者：

- **苹果 / 三星 / 华为 / 小米 / 谷歌 / OPPO / vivo 等手机厂**：与手机生态深度绑定
- **Garmin / Polar / Suunto / Coros**：运动专业品牌
- **Whoop / Oura / Ultrahuman**：健康订阅模式代表
- **传统手表品牌智能化**：TAG Heuer / 卡西欧 等

AI 化主要体现在：

- **健康指标解读**：从「显示原始数据」到「自然语言解读 + 个性化建议」
- **运动教练**：训练计划生成、姿态/呼吸纠正
- **睡眠 / 压力管理**：个性化报告与干预建议
- **语音助手**：表盘端轻量对话（受限于功耗与算力）

## 代表性产品（公开来源）

### 健康订阅样板

- **Whoop**：硬件 0 元 + ~$30/月订阅，AI 健康解读为核心卖点
- **Oura Ring**：硬件 ~$300 + ~$5.99/月订阅，睡眠/恢复 AI 报告
- **Ultrahuman Ring AIR**：硬件买断 + 可选订阅
- **Apple Fitness+ / Apple Health AI**：与生态打包

### 大众消费市场

- **Apple Watch / 华为 Watch / 小米手环**：AI 功能逐步集成
- **Galaxy Watch / Pixel Watch**：与 Gemini 类模型试点结合
- **国内华米 Amazfit / 荣耀手表**：AI 解读功能

### 专业方向

- **Garmin / Polar / Coros**：运动数据深度 + 第三方 AI 集成
- **Withings**：医疗级数据 + AI 慢病管理探索

## 主要挑战

1. **端侧算力极度受限**：表盘 SoC 远不及手机，模型只能跑在手机/云端
2. **隐私敏感度高**：心率、睡眠、地理轨迹属于高敏数据，跨境合规成本高
3. **续航 vs AI 体验**：开通后台 AI 推理会显著影响续航
4. **医疗合规**：AI 解读触及医疗建议边界，地区法规差异大
5. **订阅心智**：消费者对手表订阅普遍接受度低，Whoop / Oura 模式难复制

---

## AI 化路径的两大分支

### 分支 A：手表端 AI（弱）+ 手机端 / 云端 AI（强）

主流路径。手表只负责采集 + 简单提示，深度解读放在配套 App / 云端：

- 数据采集 → 上行到手机 / 云端
- 大模型生成日报 / 周报 / 个性化建议
- 通过 App / 通知 反馈给用户

千问大模型这类基础模型可作为「健康解读 / 教练对话 / 睡眠报告」的底座。

### 分支 B：表盘原生 AI（远期）

- 端侧蒸馏过的小模型（&lt;1B 参数）跑在表盘
- 离线场景下生成简单建议
- 受功耗约束，目前商用化仍困难

---

## 商业化探索

公开可见的订阅模式：

1. **硬件 + 内容订阅**（Whoop / Oura）：AI 解读 + 教练计划 + 月度报告
2. **硬件买断 + 可选高级订阅**（Apple / Garmin / Ultrahuman）
3. **健康 SaaS + 设备分销**（B 端：保险公司 / 企业健康管理）

国内市场目前订阅化薄弱，主流仍是「硬件买断 + 全功能免费」逻辑。

## 待观察信号

- 国内是否出现「100–500 元/年」可被大众接受的健康 AI 订阅
- 端侧小模型（≤1B）能否跑在 Wear OS / RTOS 上完成常见任务
- 大模型在「个性化健康建议」是否能突破当前「免责声明 + 通用建议」的天花板
- 是否出现医疗级 AI 解读 + 保险联动 的样板
