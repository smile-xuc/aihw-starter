# 05 · IPC（家用摄像头）

> 1 分钟读完，判断要不要继续往下看。

## 这个品类是什么

**家用 IP 摄像头 + AI 视觉理解 + 视频内容检索** 的智能安防设备品类。形态：室内云台机、室外枪机、电池机；客单价 100–500 元，叠加云存储 / AI 服务订阅。

## 商业化现状（公开信息观察）

- **是 AI 硬件中订阅模式已知跑通的代表品类**：基于「100 段视频懒得自己看」的真实痛点，AI 摘要+语义检索+事件推送形成清晰付费场景。
- **存量云存用户是最佳转化池**：已有付费习惯的用户对 AI 增值服务接受度高。
- **核心差异是「自然语言搜视频」**：摆脱按时间线翻找，改成「找昨晚 9 点小孩在沙发上跳的片段」。

> 📊 详细市场判断 → 见 [01-business.md](./01-business.md)

## 推荐架构（千问大模型版本）

摄像头 → 视频上传 OSS → **OSS AI 内容感知索引**（serverless，按需扫描存量+增量） → 用户在 App 输入自然语言 → DoMetaQuery 语义检索 → 命中的视频片段 + 千问生成的摘要描述。

> 🛠️ 完整接入步骤 → 见 [02-solution.md](./02-solution.md)

## 成本与计费

- **BOM 增量**：几乎为零（只要摄像头能上传到 OSS 即可）
- **三段计费**：数据索引 + AI 内容感知 + API 请求
- **报价口径**：月度订阅（已知跑通的市场范围 5–20 元/月，包年有折扣）
