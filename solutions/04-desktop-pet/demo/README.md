> 本目录用于存放桌宠/毛绒品类的可运行示例代码。
> 当前为占位版，欢迎社区贡献最小可运行 demo。

## 计划包含的 demo

- [ ] **`stream-tag-parser/`** — 流式标签解析器（嵌入式可移植版）
- [ ] **`emoji-action-mapping/`** — 标签到端侧动作的映射示例
- [ ] **`emotion-sync/`** — 三路同步（动作 + 表情 + 情感 TTS）
- [ ] **`servo-driver/`** — 舵机驱动示例（基于 ESP32 + LEDC）
- [ ] **`screen-emoji/`** — 屏幕表情动画素材与播放代码
- [ ] **`safety-fallback/`** — 安全兜底逻辑（自伤话题强制 neutral）
