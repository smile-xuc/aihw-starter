# AI 眼镜（AI Glasses）
## 品类概述

**带摄像头/麦克风/喇叭的眼镜形态智能终端**——以语音 + 视觉为主交互，部分形态带 AR 显示。覆盖三个细分：

1. **音频眼镜**（无显示）：偏耳机 + 拍照 + AI 助手
2. **AR 眼镜**：单/双目显示 + 拍照 + AI 助手
3. **行业眼镜**：远程协助、巡检、教学

客单价 1000–5000 元，是当前最受关注的 AI 硬件新形态之一。

## 商业化现状（公开信息观察）

- **品类正在 inflection point**：Ray-Ban Meta 验证了「眼镜 + AI」的消费场景；雷鸟、乐奇、华为眼镜、星纪魅族等多家在出货或量产爬坡。
- **核心壁垒在端侧工程**：续航、重量、佩戴舒适度比模型选型重要得多。
- **RTOS 是关键集成挑战**——眼镜大多跑 RTOS 或轻量 Linux，集成多模态对话栈不容易。

> 📊 详细市场判断 → 见 [01-business.md](./01-business.md)

## 推荐架构（千问大模型版本）

眼镜端（RTOS / Linux）→ **多模态交互开发套件 SDK**（内置 VAD / 回声消除 / 唤醒词 / 全双工对话引擎）→ 千问 LLM + Omni 多模态 + 视觉理解（文物/地标/药品/绘本等场景模板） → 流式 TTS 回播。

> 🛠️ 完整接入步骤 → 见 [02-solution.md](./02-solution.md)

## 成本与计费

- **BOM 增量**：取决于显示模组（无显示便宜很多，AR 双目最贵）
- **Token 成本**：含视觉调用一次约 0.01–0.05 元
- **多模态交互开发套件**：套餐 / 按次计费两种模式
