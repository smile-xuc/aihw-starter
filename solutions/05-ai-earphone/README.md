# AI 耳机（AI Earphone）
## 品类概述

**带 AI 能力的无线耳机**——覆盖三个细分场景：

1. **AI 翻译耳机**：实时多语种同传、跨境商务/旅行
2. **AI 对话耳机**：语音助手、智能问答、信息查询
3. **AI 转写耳机**：会议录音 + 实时字幕

客单价 300–2000 元，是 AI 硬件中**出货量最大的品类之一**——白牌耳机年出货可达千万级。

## 商业化现状（公开信息观察）

- **走量靠白牌、品牌靠体验**：白牌耳机的 AI 是「卖点而非主战场」，激活率不一定高；品牌厂商把 AI 做深做透才能抗白牌。
- **翻译场景已被验证**：60+ 语种 + 3 秒延迟的体验已能覆盖主要商旅场景。
- **真无线耳机 SoC 算力有限**——音频处理大头在云端，端侧只做唤醒、降噪、传输。

> 📊 详细市场判断 → 见 [01-business.md](./01-business.md)

## 推荐架构（千问大模型版本）

耳机端 SoC（仅做唤醒/降噪/语音传输） → 配套 App / 网关 → **Qwen-LiveTranslate** 多语种实时翻译 / **多模态交互引擎** 实时对话 → TTS 流式回播。

> 🛠️ 完整接入步骤 → 见 [02-solution.md](./02-solution.md)

## 成本与计费

- **BOM 增量**：5–30 元（取决于是否升级麦克风阵列与天线模组）
- **翻译场景**：按音频时长计费，60 种语言全包
- **对话场景**：按 token 计费
