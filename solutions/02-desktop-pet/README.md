# 02 · 桌宠（Desktop Pet）

> 1 分钟读完，判断要不要继续往下看。

## 这个品类是什么

**带屏幕情绪表达 + 舵机肢体动作 + AI 对话** 的桌面陪伴设备。客单价 500–2000 元，面向年轻人/办公场景的情感陪伴与小空间互动。代表形态：表情屏 + 舵机摆头/挥手 + 语音对话三路同步。

## 商业化现状（公开信息观察）

- **品类正在快速形成**：从早期的「电子宠物玩具」演化为「办公桌伴侣」，叠加 AI 后想象空间打开。
- **核心壁垒在交互体验**：动作表情情绪三路同步的细节，比单纯堆模型重要得多。
- **目前没有跑通的订阅模式**——多数厂商在「卖硬件 + 偶尔升级固件」阶段。

> 📊 详细市场判断 → 见 [01-business.md](./01-business.md)

## 推荐架构（千问大模型版本）

LLM 一次推理同时输出 **文字回复 + 情绪标签 + 动作标签**（如 `[emoji-happy] [action-wave] 你好呀！`），端侧解析后并行驱动屏幕表情、舵机动作、TTS 播报，避免多次推理叠加延迟。

> 🛠️ 完整接入步骤 → 见 [02-solution.md](./02-solution.md)

## 成本与计费

- **BOM 增量**：100–300 元（屏 + 舵机 + 麦克风 + 主控）
- **Token 成本**：单次完整对话约 0.005 元（千问目录价）
- **续航 vs 算力**：插电用旗舰、电池用轻量+本地缓存

> 💰 详细测算 → 见 [03-cost.md](./03-cost.md)
