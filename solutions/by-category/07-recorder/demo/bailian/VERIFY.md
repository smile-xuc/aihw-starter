口径：

- **首字延迟**：录音结束（开始上传）→ 纪要首个 token，含上传与转写；分项耗时在备注中。
- **单次成本**：转写与总结的完整有效 Token `usage` × 地域单价；输入 / 输出均须是非负整数，显式 0 保留为已知，缺失或无效值不当零。
- **未知费用**：filetrans 仅返回 `duration` 时转写费用未知，不按音频时长或文字长度估算。任一阶段缺完整有效 Token 用量，总费用未知；实际以账单为准。
- **路线**：默认「临时上传 + filetrans」；公网 URL 使用 filetrans；旧同步仅供显式 `--sync` 对比。
- **声道**：本地 WAV / MP3 自动探测，其他格式和 URL 显式传 `--channels 1/2`；单声道分离说话人，双声道保留两轨并按时间排序，超过 2 声道拒绝处理。所有请求声道均须返回，漏轨不能视为成功。
- **新增记录**：`python3 run.py --record` 真跑成功后在下表追加一行，提交前补验证人与网络环境。
