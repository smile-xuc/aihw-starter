## 一、硬件 BOM 参考

以「信用卡大小录音卡 + 麦阵 + Wi-Fi/BLE + 本地存储」为基准，批量约 1k pcs：

| 组件 | 参考单价（元） | 说明 |
|---|---:|---|
| 主控（低功耗 MCU / 应用处理器） | 15–50 | 仅录音可 MCU；本地预处理再上 SoC |
| 麦克风（双麦 / 阵列） | 5–25 | 远场会议盒子麦阵更贵 |
| 存储（eMMC / Flash 16–64GB） | 10–40 | Plaud 类公开宣称数十 GB 级内置存储 |
| 电池 + 充电 | 10–30 | 长续航是卖点 |
| Wi-Fi / BLE 模组 | 5–20 | 上传转写依赖连接 |
| 外壳 + 结构（含磁吸壳） | 10–40 | 磁吸 / 笔形模具差异大 |
| PCB + 贴片 | 8–20 | — |
| **合计** | **约 70–200** | 不含认证与包装 |

会议盒子（桌面多麦）BOM 通常显著更高（麦阵 + 扬声器 + 更大外壳），零售也更高。

## 二、云端 AI 成本测算

### 2.1 端到端（1 小时音频）量级

| 环节 | 时延量级 | 成本量级 |
|---|---|---|
| ASR（Paraformer 文件版等） | 1–3 分钟 | ¥0.5–1.5 |
| 说话人分离 | 30–60 秒 | 计算可忽略或并入 ASR |
| LLM 摘要（qwen-plus Map-Reduce） | 20–60 秒 | ¥0.3–2.0 |
| **合计** | **2–5 分钟** | **约 ¥1–4 / 小时** |

> 计费页以官方为准：https://help.aliyun.com/zh/model-studio/billing-of-model-studio

实时流式 ASR 单位时长通常略高于文件版；纪要仍在会后用 LLM 生成。

### 2.2 对照公开订阅锚点（Plaud）

| 计划（公开） | 价格 | 包含分钟 | 粗算「若自建云端」余量 |
|---|---|---|---|
| Starter（随硬件） | $0 | 300 min/月 | 约 5 小时；按 ¥1–4/h 云成本约数元～二十元人民币量级 |
| Pro（年付折月） | 约 $8.33/月（$99.99/年） | 1200 min/月 | 约 20 小时 |
| Unlimited（年付折月） | 约 $19.99/月（$239.99/年） | 公开至 24h/天档 | 重度用户；须严格控 ASR 与摘要档位 |

来源：https://www.plaud.ai/pages/plaud-ai-plan-pricing · https://www.plaud.ai/products/plaud-note-ai-voice-recorder

**含义**：海外标杆用「赠送 300 分钟 + 付费加购」对齐云端成本；自建链路时应用 **VAD 剪静音 + 分级摘要** 把重度用户成本压在 ARPU 之下。

### 2.3 优化杠杆

1. **VAD 预过滤**：沉默不送 ASR，常见可省 30–50% 时长
2. **分级摘要**：默认 qwen-flash/plus；用户点「深度分析」再升 max
3. **结果缓存**：同一录音不重复摘要
4. **对象存储生命周期**：转写后限期删原音（注意合规留存要求）

## 四、成本结构概览

```
┌─────────────────────────────────────────┐
│  硬件 BOM              25–40%           │
│  渠道营销              20–35%           │
│  赠送分钟云端预提       5–15%           │
│  认证 / 售后           5–10%            │
│  品牌毛利              其余             │
└─────────────────────────────────────────┘
订阅期：云端成本应稳定低于 ARPU；超限用分钟包或限速。
```

**结论**：录音卡是少数 **订阅逻辑清晰** 的 AI 硬件品类。工程上盯「每小时云成本」；商业上盯「赠送分钟 + 付费转化」。

> ASR 时长 + 纪要 LLM 与「音频 token / 文本 token」账单通识见 [primer/04 · Token 与计费](../../../primer/04-token-billing.md)。
