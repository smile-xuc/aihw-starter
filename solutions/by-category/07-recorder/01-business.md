## 一、品类利润逻辑

### 1.1 卖的是「音频 → 可读工作产物」，不是麦克风

录音卡的购买心智是**生产力工具**：用户为「录完就能出纪要 / 决策 / 待办」付费。硬件是低成本采集器，价值在云端 ASR + 纪要 Agent。

| 路线 | 加价逻辑 | 谁在做 | 备注 |
|---|---|---|---|
| **卡片机 + 订阅（海外主航道）** | BOM 低 → 零售 $149–189 + 月费 | Plaud Note / Note Pro、Notta Memo | 硬件铺货，订阅吃 ARPU |
| **专业录音笔（国内主航道）** | BOM 较高 → 零售 ¥1000–2500 + 时长包 | 讯飞 SR 系列等 | 硬件溢价 + 听见生态 |
| **可穿戴持续录音** | 极简硬件 → $99 量级 + 订阅 | Limitless Pendant（公开停售） | 隐私与合规压力大 |
| **会议盒子 / 桌面** | 麦阵列 + 屏 → 更高客单 | 企业会议设备 | 常走 B 端项目交付 |

对方案商 / 品牌商的含义：

- **没有摘要差异化** → 只能卷转写准确率与价格，毛利薄
- **有垂直模板（销售 / 法律 / 医疗）** → 才有资格抬订阅 ARPU
- **不要用桌宠的「买断摊销」模型套录音卡**：本品类用户已接受按时长付费

### 1.2 当前阶段：硬件低价 + 云端时长订阅

公开市场观察（海外标杆）：

```
硬件一次性售价（$149–189）
  + 设备附赠 Starter 时长（如 300 min/mo）
  → 重度用户升级 Pro / Unlimited
  → 订阅成为主要经常性收入
```

公开定价（以官网为准，访问日可能变动）：

| 产品 / 套餐 | 公开价 | 来源 |
|---|---|---|
| Plaud Note | $159 USD，含 Starter 300 min/mo | [Plaud Note 产品页](https://www.plaud.ai/products/plaud-note-ai-voice-recorder) |
| Plaud Note Pro | $189 USD | [Plaud Note Pro](https://www.plaud.ai/products/plaud-note-pro) |
| Plaud Pro Plan（年付折月） | ~$8.33/mo（$99.99/yr），1200 min/mo | [Plaud AI Plan Pricing](https://www.plaud.ai/pages/plaud-ai-plan-pricing) |
| Plaud Unlimited（年付折月） | ~$19.99/mo（$239.99/yr），至 24h/天 | 同上 |
| Notta Memo | $149 USD，含 Starter 300 min/mo（公开表述） | [Notta Memo](https://www.notta.ai/en/hardware/memo) / [商店](https://shop.notta.ai/en-us/products/notta-memo) |
| 讯飞 SR502 星火版 | 官网标价 ¥2499（促销常见浮动） | [讯飞录音笔官网参数页](https://www.iflytekrecord.com/Goods_parms/1/511.html) |

### 1.3 下一阶段：跨会议检索与工作流，才是留存

从「单次录音出纪要」走向「知识库」，公开可见的演进方向：

| 能力 | 作用 | 现状 |
|---|---|---|
| **Map-Reduce 结构化纪要** | 决策 / 待办 / 风险可勾选 | 技术方案成熟，见 [`02-solution.md`](./02-solution.md) |
| **说话人分离 + 热词** | 会议可读性与行业准确率 | 文件版 diarization 可用 |
| **跨会议检索 / Ask** | 问「上周客户承诺了什么」 | Plaud Ask、听悟类能力已公开 |
| **飞书 / 钉钉 / Zapier 闭环** | 纪要直接变任务 | 留存关键；否则「录完即弃」 |

**逻辑链**：转写保底线 → 结构化摘要做付费理由 → 工作流集成做续费 → 才谈得上高 ARPU Unlimited。

## 二、形态与客户画像

### 2.1 四种形态

| 形态 | 典型 BOM 增量 | 客单参考（公开） | 关键卖点 |
|---|---|---|---|
| 卡片 / 夹式录音卡 | 30–60 元 | $149–189 / ¥200–800 | 薄、可贴手机、双模式录音 |
| 挂绳 / 可穿戴 | 40–80 元 | ~$99（历史公开价） | 全天候采集，隐私敏感 |
| 智能录音笔 | 80–200 元 | ¥1000–2500 | 屏、离线转写、专业麦 |
| 会议盒子 | 更高 | B 端项目价 | 桌面麦阵列、实时字幕 |

### 2.2 四类客户

| 类型 | 特征 | 适合路线 |
|---|---|---|
| 商务 / 律师 / 医生 | 高 ARPU、强专业语料、愿付 Unlimited | 卡片机 + 垂直模板 + 合规 |
| 学生 / 课堂 | 低 ARPU、量大、强课堂场景 | 低硬件价 + 基础时长包 |
| 媒体 / 采访 | 中频高质、转写质量优先 | 专业麦 + 高精度 ASR |
| 企业客户 | B 端交付、合规存档、席位管理 | 会议盒子 / Team 套餐 |

### 2.3 与相邻品类的边界

| 判断维度 | 走录音卡（本品类） | 走耳机 [`06`](../06-ai-earphone/) | 走纯 SaaS |
|---|---|---|---|
| 采集形态 | 独立硬件主录音 | 耳机附带录音 | 手机 / Zoom 插件 |
| 付费心智 | 时长包 / 订阅清晰 | 常摊进耳机售价 | 纯软件席位 |
| 差异化 | 麦质量 + 纪要模板 | 翻译 / 通话体验 | 集成与协作 |

## 三、订阅可行性：本品类已知可跑通

**结论：海外公开市场已有跑通的「硬件 + AI 转写订阅」案例（Plaud 等）；国内以「硬件 + 听见时长包 / 会员」为主。**

已知模式：

1. **设备附赠 Starter 时长** → 降低首次决策门槛，养成「录完看纪要」习惯
2. **Pro / Unlimited 按时长升级** → 重度用户（销售、律师）自然升级
3. **Team 席位** → B 端集中管理与共享文件
4. **警惕「录完即弃」**：会议结束后多数用户不回看——必须用待办提醒、日历同步、Ask 检索拉回产品

**建议**：

- 订阅价值包装为「转写分钟 + 高级摘要模板 + 多端同步 + 工作流」，而不是「多一点准确率」
- 成本侧按「月均录音小时 ×（ASR + LLM）」测算，见 [`03-cost.md`](./03-cost.md)
- 架构上预留跨会议向量检索，作为下一阶段续费锚点

## 四、毛利结构（量级）

仅作行业一般性陈述，非任何具体厂商数据：

```
卡片机（零售约 $159 / ¥1100 档）示意：

  零售价：              ~1100 元量级
  - 渠道与营销：       150–300 元
  - 硬件 BOM + 组装：   80–200 元
  - 首年云端赠送时长：  视套餐，需按官方 ASR/LLM 单价核算
  - 认证 / 售后预提：    20–50 元
  ─────────────────────────────
  品牌侧毛利空间：     强依赖渠道；经常性收入看订阅转化
```

三个结论：

1. 单次硬件毛利可接受，但**真正的生意在订阅转化率与月均录音时长**
2. 云端成本随重度用户线性上升——Unlimited 必须控模型档位与 Map-Reduce 切段策略
3. 国内高客单录音笔可更多吃硬件溢价，但仍需时长包养活重度使用

## 五、决策树：要不要做录音卡

```
用户愿不愿为「纪要」付钱？
  ├─ 不愿意 → 不要做独立录音卡，把录音当耳机/手机附赠功能
  └─ 愿意
       ├─ 目标市场在海外？
       │    ├─ 是 → 卡片机 + Starter 赠送 + Pro/Unlimited，对标 Plaud/Notta
       │    └─ 否 → 评估国内录音笔渠道 vs 低价卡片机；合规与听见生态
       └─ 有没有垂直场景（法律/医疗/销售）？
            ├─ 有 → 模板与热词做成壁垒，可抬 ARPU
            └─ 没有 → 拼麦质量、续航、双模式录音与摘要稳定性
```

## 六、品类适配速查

| 问题 | 建议 |
|---|---|
| 只要手机录音 + 转写 | 可不做硬件，接听悟 / 自拼 Paraformer + 千问 |
| 要独立采集、贴手机、双模式 | 做卡片机，走文件转写 + Map-Reduce |
| 要边录边出字幕 | 会议盒子 / 实时流式，见 [`02-solution.md`](./02-solution.md) |
| 要全天候可穿戴 | 先过隐私与告知合规，再谈产品 |
