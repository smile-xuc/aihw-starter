## 品类定义

带传感器（心率/血氧/加速度/体温）的腕上设备，结合大模型实现**健康数据解读**与**个性化建议**。客单价 300–5000 元。

### 细分品类

| 细分 | 代表形态 | 客单价 |
|------|----------|--------|
| 运动手表 | GPS+心率+运动模式识别 | 800–3000 元 |
| 健康监测手环 | 心率+血氧+睡眠 | 300–800 元 |
| 医疗级可穿戴 | ECG+连续血糖+体温 | 2000–5000 元 |

## 核心大模型能力

- **健康指标解读**：替代传统查表，用自然语言解释心率变异性、血氧趋势等
- **异常预警**：识别数据异常模式，主动推送告警
- **订阅制健康报告**：周报/月报自动生成，个性化建议

## 推荐架构

```
[传感器数据] → [端侧预处理/特征提取]
                      │
                      ▼
          [云端 LLM 健康解读引擎]
           ├─ 指标趋势分析
           ├─ 异常模式识别
           └─ 个性化建议生成
                      │
                      ▼
         [App 推送 / 表盘卡片 / 语音播报]
```

## 商业化模式

硬件销售 + 订阅制增值服务：

| 收入来源 | 定价参考 |
|----------|----------|
| 硬件一次性 | 300–5000 元 |
| 健康日报推送 | 免费（引流） |
| 深度健康报告 | 9.9–29.9 元/月 |
| 家庭共享套餐 | 49.9 元/月 |
