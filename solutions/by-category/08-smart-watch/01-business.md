## 一、品类利润逻辑

### 1.1 卖的是「连续体征 + 可信解读」

购买心智接近**健康管理配件 / 运动装备**：用户为「戴着就能看到趋势、听得懂建议」付费。大模型是解读层，不是单独 SKU。

| 路线 | 加价逻辑 | 公开代表 | 备注 |
|---|---|---|---|
| **硬件买断 + 可选会员** | BOM → 零售溢价；会员加深洞察 | Oura Ring 5 ≈ $399 + $5.99/月 | 会员可选，基础分可看 |
| **订阅含硬件** | 年费捆绑设备 | WHOOP One/Peak/Life ≈ $199–$359/年 | 取消订阅即失核心能力 |
| **旗舰表 + 生态订阅** | 高客单硬件 + Fitness+ 等 | Apple Watch Ultra 3/4 ≈ $799 起；Fitness+ $9.99/月 | AI 能力多在系统层 |
| **国产旗舰 + App 会员** | 硬件为主；会员课程 / 计划 | 华为 WATCH 6 Pro ≈ ¥3499 起；活力人生连续包月 15 元 | AI 健康解读随表 / 会员 |

### 1.2 订阅：海外部分跑通，国内偏增值

**已知跑通（公开）**：

- Oura Membership：$5.99/月或 $69.99/年（[ouraring.com/membership](https://ouraring.com/membership)）
- WHOOP：硬件含于会员，$199 / $239 / $359 年（[whoop.com/membership](https://www.whoop.com/us/en/membership/)）

**国内观察**：华为运动健康「活力人生」连续包月 **15 元**、年卡 **208 元**（[华为支持页](https://consumer.huawei.com/cn/support/content/zh-cn15839131/)）；硬件仍是主现金流，会员是留存与 ARPU 增量。

### 1.3 合规边界

不做医疗诊断 / 处方；异常只做「建议就医」。医疗器械注册与广告法另案评估。Demo 与 Prompt 须硬编码免责声明。

## 二、形态与客户

| 形态 | 客单参考 | 客户 |
|---|---|---|
| 入门手环 | 300–800 元 | 走量、渠道礼品 |
| 运动手表 | 800–3000 元 | 运动爱好者 |
| 旗舰智能表 | 2000–5000+ 元 | 生态锁定用户 |
| 指环 / 无屏带 | $349–$499 + 会员 | 睡眠 / 恢复向 |

## 三、决策树

```
核心价值是「体征连续监测 + 解读」？
  ├─ 否 → 不要做手表品类
  └─ 是
       ├─ 目标市场在海外且愿做订阅？
       │    ├─ 是 → 对照 Oura（可选会员）或 WHOOP（强制会员）
       │    └─ 否 → 硬件买断 + 轻量会员（课程/计划/深度报告）
       └─ 是否宣称医疗级？
            ├─ 是 → 先法规与注册路径，再谈 LLM 文案
            └─ 否 → Prompt 免责 + [ALERT] 阈值即可上线 MVP
```
