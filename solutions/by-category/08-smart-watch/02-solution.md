## 两种集成模式对比

| 维度 | Prompt 模式（快速） | RAG + Agent 模式（深度） |
|------|---------------------|--------------------------|
| 输入 | 结构化指标 JSON | 指标 + 用户历史 + 医学知识库 |
| 输出 | 单次文本解读 | 多轮对话 + 行动建议 + 报告 |
| 适用 | MVP / 日报推送 | 深度健康管理订阅 |
| 成本 | ~0.002 元/次 | ~0.02 元/次 |
| 准确性 | 通用解读，偶有泛化 | 个性化，可引用医学文献 |

## 数据管线架构

```
[手表传感器] → [蓝牙同步App] → [数据标准化]
```

## Prompt 模板示例

```text
角色设定：专业健康顾问。根据以下用户今日健康数据，给出简洁的健康解读和建议。

## 用户画像
- 性别: {{gender}}, 年龄: {{age}}, BMI: {{bmi}}

## 今日数据
- 静息心率: {{rhr}} bpm（7日均值: {{rhr_avg}}）
- 血氧: {{spo2}}%（最低: {{spo2_min}}%）
- 深睡时长: {{deep_sleep}} min / 总睡眠: {{total_sleep}} min
- 步数: {{steps}}, 活动热量: {{cal}} kcal

## 输出要求
1. 一句话总结今日状态（≤20字）
2. 需关注项（如有异常）
3. 一条可执行建议

注意：不做医疗诊断，异常指标建议就医。
```

## 关键约束

| 约束项 | 要求 | 实现方式 |
|--------|------|----------|
| 隐私合规 | 健康数据不出境，符合《个人信息保护法》 | 国内云部署 + 数据加密 |
| 医疗免责 | 明确标注"非医疗建议" | System Prompt 硬约束 + 输出后缀 |
| 数据脱敏 | LLM 侧不存储原始数据 | 仅传聚合指标，不传原始波形 |
| 延迟要求 | 日报 < 5s，异常告警 < 30s | 异步队列 + 流式输出 |

## System Prompt 片段

```text
# Role
角色设定：「健康助理」，服务于智能手表用户。

# Rules
- 永远不做医疗诊断或处方建议
- 检测到危险阈值时，首句输出 [ALERT] 标签
- 所有输出末尾附加：「以上为AI健康参考，不替代专业医疗意见」
- 使用通俗语言，避免过度医学术语
- 对比用户历史基线，指出趋势变化
```
