# samples · 模拟设备输入

| 文件 | 模拟 | 内容 | 来源 |
|---|---|---|---|
| `day_normal.json` | 手表经手机 App 同步的一天聚合指标 | 无红线；总睡眠 5 小时 40 分、静息心率比 7 日均值高 10 次/分、夜间血氧最低 93% | 复制自旧 demo [`metrics-prompt/sample_day.json`](../../metrics-prompt/sample_day.json)，本仓编写的虚构数据 |
| `day_alert.json` | 同一位虚构用户的另一天 | 夜间血氧最低 87%（触发「低于 90%」红线）、静息心率比 7 日均值高 22 次/分、深睡 41 分钟 | 本仓编写的虚构数据，2026-10-01 |

两份都是虚构数据，不来自真实用户。

## 字段

| 字段 | 含义 | 单位 |
|---|---|---|
| `gender` / `age` / `bmi` | 用户画像（只用于解读口径） | — / 岁 / — |
| `rhr` | 静息心率 | 次/分 |
| `rhr_avg7` | 近 7 日静息心率均值 | 次/分 |
| `spo2` | 血氧均值 | % |
| `spo2_min` | 夜间血氧最低值 | % |
| `deep_sleep_min` / `total_sleep_min` | 深睡 / 总睡眠 | 分钟 |
| `steps` / `cal` | 步数 / 活动热量 | 步 / 千卡 |

换成自己的数据：按上表字段写一个 JSON，`python3 run.py --day my_day.json`。只放聚合指标，不放原始 PPG 波形、姓名、手机号等标识信息。
