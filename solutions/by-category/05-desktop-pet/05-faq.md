## A. 商业模式与订阅

**Q1：桌宠订阅能跑通吗？**
A：截至当前版本，公开市场**未见跑通**的桌宠 AI 月度订阅。购买心智接近摆件 / IP 周边，用户为一次性体验付费。建议把云端成本摊进硬件售价；订阅若做，宜包装为「日记备份 / 多设备同步」类年费，而不是「聊天月费」。详见 [`01-business.md`](./01-business.md) 第三节。

**Q2：桌宠和玩具陪伴怎么选？**
A：看有没有**表情 / 动作 / 灯光**输出。纯语音毛绒、AI 挂件走 [`03-toys-companion`](../03-toys-companion/)；带屏表情或舵机动作走桌宠，多一层标签嵌入式三路同步。

**Q3：没有 IP 能不能做桌宠？**
A：能，但应走轻硬件（客单约 199–399 元），把三路同步与工业设计做稳。没有 IP 却按 800+ 元定价，公开市场很难支撑。决策树见 [`01-business.md`](./01-business.md) 第五节。

**Q4：日活不够高怎么办？**
A：桌宠常见「买了当摆件」。公开可观察的提活手段：主动轻互动（限频）、触摸快捷动作、每日日记可分享——注意合规上不得以诱导沉迷为产品目标。

## B. 模型与链路选型

**Q5：默认用 flash 还是 plus？**
A：工位低频 → qwen-flash；主流陪伴对话 → qwen-plus。不要默认 max：贵且首字更慢，对桌面短对话不友好。测算见 [`03-cost.md`](./03-cost.md)。

**Q6：要不要上 Omni / Audio-3.0 Realtime？**
A：对话是主体验、客单吃得下音频时长成本、需要打断与拟人节奏时再上。白牌摆件继续三段式即可。延迟对照见 [`../../benchmark/`](../../benchmark/)。

**Q7：情感 TTS 哪些音色可用？**
A：cosyvoice-v3-plus / flash 支持多档情绪，但**仅部分音色**吃 emotion 参数（如龙安欢、龙安洋、龙呼呼、龙火火、龙川叔等，以官方音色页为准）。其他音色传参会被忽略。

**Q8：标签会不会把 token 打得很贵？**
A：单个 `[emoji-01]` 只占数个 token；真正的成本来自堆叠。system prompt 限制「每轮最多 1 emoji + 1 action」，既省钱也改善动作排队体验。

## C. 三路同步与端侧

**Q9：动作和说话怎么同步？**
A：LLM 流式输出 → 端侧流式标签解析：收齐完整标签再触发屏 / 舵机，去标签文本送 TTS。见 [`02-solution.md`](./02-solution.md) 第八节与 [`demo/stream-tag-parser/`](./demo/stream-tag-parser/)。

**Q10：为什么必须流式解析，不能等整句？**
A：等整句再动，用户会感觉「说完了才开始演」。流式解析可在说话过程中触发表情 / 动作；但标签可能跨多个 token，**未收齐前不能触发**，否则会「话没出口先动手」。

**Q11：动作堵转、抖动怎么处理？**
A：固件为每个 action 设最大执行时长，超时强制归位；同一动作设冷却（默认约 1 秒）；队列可插队取消（打断场景）。

**Q12：Wi-Fi 不好还能聊吗？**
A：可做 BLE Opus 经手机代理上云，延迟大约再高 0.5–1 秒，功能可保留。见 [`02-solution.md`](./02-solution.md) 第六节。

**Q13：能不能完全本地跑大模型？**
A：消费级桌宠 BOM 下，完整本地 LLM 通常不划算。可行组合是：端侧唤醒 / VAD / 动作表本地化 + 云端对话；离线仅保留兜底语料与本地表情。

---

## D. 记忆日记与运营

**Q14：记忆日记一定要做吗？**
A：不是 MVP 必选项，但是从「会说话的摆件」到「专属伙伴」的主差异化。日终用 flash 摘要，成本通常低于升级模型档位。见 [`02-solution.md`](./02-solution.md) 第五节。

**Q15：人格会不会漂？**
A：单靠长 context 会漂。需要：固定人设段落 + 记忆摘要注入 +（可选）Agent 后台热更新 prompt。不要把全部历史原文塞进每轮请求。

## E. 合规与安全

> ⚖️ 《人工智能拟人化互动服务管理暂行办法》2026-07-15 施行，「持续性情感互动服务」纳入监管，桌宠直接适用。
>
> - 算法备案；上线或达用户规模阈值时安全评估
> - AI 身份标识；超 2 小时使用提醒；不得以诱导沉迷依赖为服务目标
> - 面向未成年人：未成年人模式、监护人同意、虚拟亲密关系禁令等
> - 原文：<a href="https://www.cac.gov.cn/2026-04/10/c_1777558395078289.htm" target="_blank" rel="noopener noreferrer">网信办发布页</a>

**Q16：自伤 / 暴力话题怎么处理？**
A：情绪强制 `neutral`，引导积极话题，必要时触发本地安全回复、不上舵机夸张动作。见 [`02-solution.md`](./02-solution.md) 安全兜底。

**Q17：工位桌宠面向成年人还要合规吗？**
A：要。成年向仍属拟人化互动服务范畴时，AI 标识、防沉迷提醒、内容安全仍适用；未成年人相关条款按实际用户结构评估。
