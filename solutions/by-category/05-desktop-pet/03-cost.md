## 一、硬件 BOM 参考

以「表情屏 + 2–4 舵机 + Wi-Fi」典型桌宠为基准，批量约 1k pcs 量级：

| 组件 | 参考单价（元） | 说明 |
|---|---:|---|
| 主控（ESP32-S3 / 同类） | 15–35 | 轻量桌宠主流；本地推理再上 RK / 全志档 |
| 表情屏（1.3″ TFT 240×240 级） | 12–25 | SPI，驱动简单；更高分辨率按需上浮 |
| 舵机 ×2–4 | 8–40 | SG90 级；四舵机含俯仰 / 摆臂 |
| 麦克风（INMP441 或 2-mic） | 3–12 | 桌面近场单麦通常够用 |
| 功放 + 喇叭 | 5–12 | I2S 1–3W，桌面场景足够 |
| Wi-Fi / BLE | 常含于主控 | 独立模组另计 5–15 |
| 电池 / USB-C 供电 | 0–20 | 插电可省电池管理 |
| 外壳 + 结构件 | 15–50 | 小批量 3D 打印贵，开模后下降 |
| PCB + 贴片 | 8–20 | 视层数与器件密度 |
| **合计** | **约 70–200** | 不含认证与包装 |

**插电 vs 电池**：

| 维度 | 插电（USB-C） | 电池 |
|---|---|---|
| 适用 | 工位桌宠、床头伴侣 | 便携毛绒、可挪动陪伴 |
| 功耗 | 可持续 Wi-Fi + 舵机 | 需休眠与间歇唤醒 |
| BOM | 无电池管理，约省 10 元 | +电芯 + 充放电 IC |
| 体验 | 无续航焦虑 | 可移动，但需日充 |

## 二、云端 AI 成本测算

### 2.1 单轮消耗（标签嵌入式）

一次完整往返通常包括：

```
用户输入：50–150 tokens（含短上下文）
模型输出：80–200 tokens（含 [emoji-xx][action-xx] + 短句）
TTS：20–60 字
合计：约 150–400 tokens + 几十秒级 TTS
```

动作 / 表情标签嵌在文本里，**不另计费**；但每个标签约占数个 token，须在 system prompt 里限制「每轮最多 1 emoji + 1 action」，避免堆叠浪费并破坏体验。

### 2.2 三段式链路（主流）

> 口径：ASR → LLM → 情感 TTS。目录价随官方调整，下表只给量级。计费页：https://help.aliyun.com/zh/model-studio/billing-of-model-studio

| 日均轮次 | 模型组合 | 月成本 / 台量级 | 适用 |
|---|---|---|---|
| ~5（轻度） | qwen-flash + cosyvoice flash | 0.3–1 元 | 工位伴侣、低频互动 |
| ~20（中度） | qwen-plus + cosyvoice v3 | 1–4 元 | 主流桌宠 |
| ~50（重度） | qwen-plus + cosyvoice v3 | 3–10 元 | 高活跃潮玩；需评估是否切 Realtime |

按 **2 年摊销** 计入硬件售价时：中度用户约 **25–100 元/台** 量级的云端预提——在 399–699 元零售档可吸收。

### 2.3 Realtime 链路（旗舰可选）

Qwen-Omni-Realtime / Qwen-Audio-3.0-Realtime 按音频时长计费，单位时长成本显著高于三段式。适合：

- 客单 ≥ 800 元、对话是主体验
- 需要语义打断与拟人节奏

不适合：白牌工位摆件、日活轮次低的礼品款。架构说明见 [`../../by-solution/01-qwen/omni-realtime/`](../../by-solution/01-qwen/omni-realtime/)，延迟横评见 [`../../benchmark/`](../../benchmark/)。

### 2.4 记忆日记增量

| 环节 | 频率 | 成本量级 |
|---|---|---|
| 日终摘要提炼（qwen-flash） | 1 次/天 | < 0.01 元/台/天 |
| 周合并 / 衰减 | 1 次/周 | 可忽略 |
| 召回注入 system prompt | 每轮 | 主要增加 input tokens，需控摘要长度 |

记忆系统对云端成本的增量通常远小于「把模型从 flash 升到 max」；优先做记忆，而不是默认上旗舰推理。

## 三、售价与规模效应

| 量级 | BOM 均价量级 | 建议零售区间 | 备注 |
|---|---:|---|---|
| 样机 1–10 | 150–250 元 | 非卖品 | 3D 打印外壳推高 |
| 小批 100–500 | 100–160 元 | 399–699 元 | 开模前谨慎承诺售价 |
| 量产 1k+ | 70–120 元 | 299–599 元 | 轻硬件主流带 |
| 大批 10k+ | 60–100 元 | 199–499 元 | 渠道决定能否下探 |

### 空白模板

```
单台 BOM：__________ 元
  + 组装测试：__________ 元
  + 包装物流：__________ 元
  + 渠道营销：__________ 元
  + 首年云端预提：__________ 元（日均轮次 × 单轮成本 × 365）
  + 品牌毛利：__________ 元
  = 目标零售价：__________ 元

是否上 Realtime：是 / 否
  - 是 → 按「日均语音分钟数 × 目录价」重算，不要用三段式表估算
```

## 四、成本结构概览

```
┌─────────────────────────────────────────┐
│  硬件 BOM + 贴片     45–60%             │
│  组装测试            10–15%             │
│  包装物流            8–12%              │
│  渠道营销            15–25%（差异最大） │
│  云端 AI（2 年摊）   2–8%               │
└─────────────────────────────────────────┘
```

**结论**：桌宠毛利敏感点在渠道与开模，不在 token。技术侧把单轮成本压在 flash / plus 档、限制标签数量、记忆用 flash 离线跑，即可把云端占比压到个位数百分点。
