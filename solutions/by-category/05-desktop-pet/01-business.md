## 一、品类利润逻辑

### 1.1 卖的是「工艺品体验」，不是「AI 功能包」

桌宠的购买心智更接近**桌面摆件 / IP 周边 / 工位礼品**：用户为「放在桌上会动、会笑、会说话」的整体体验付一次性溢价。AI 是体验的一部分，不是单独可卖的 SKU。

| 路线 | 加价逻辑 | 谁在做 | 备注 |
|---|---|---|---|
| **轻硬件溢价（主流创业路径）** | BOM 60–150 元 → 零售 199–599 元 | Looi 类充电头 / ESP32 开源复刻 / 国内工位桌宠 | 软件定义体验，硬件极简 |
| **中硬件情感标杆** | BOM 200–400 元 → 零售 999–2000 元 | EMO、部分国内双足 / 独轮桌宠 | 表情与自主行为是壁垒 |
| **重硬件收藏向** | BOM 更高 → 零售 $300+ | Vector / Cozmo 系 | 传感与自主探索强，LLM 往往后装 |

对方案商 / 品牌商的含义：

- **没有 IP、没有工业设计能力** → 轻硬件路线仍可成立，但必须把「三路同步」做到不出戏，否则与纯语音玩具无差异
- **有 IP 或有表情 / 动作素材产能** → 才有资格走中硬件溢价；表情丰富度比模型档位更决定复购口碑
- **不要用玩具的「走量 +40 元」模型套桌宠**：桌宠客单更高、出货更慢，单台净利要靠体验溢价，不靠薄利多销

### 1.2 当前阶段：硬件买断 + 云端成本内嵌

公开市场观察：

```
云端 ASR / LLM / TTS 年费（个位数～十几元/台）
  → 摊进硬件一次性售价
  → 用户买断，默认「会聊到死」
```

用户不接受「桌宠还要月费」的心智。月度订阅在本品类**已知未跑通**（见第三节）。

### 1.3 下一阶段：记忆与日记才是黏性，不是更贵的模型

从「会说话的摆件」走向「专属伙伴」，公开可见的演进方向：

| 能力 | 作用 | 现状 |
|---|---|---|
| **动作情绪三路同步** | 说什么 + 做什么 + 什么情绪一次出齐，不出戏 | 技术方案已成熟，见 [`02-solution.md`](./02-solution.md) |
| **每日记忆日记** | 记住喜好与事件，第二天还能接话 | 头部产品在做；是差异化主战场 |
| **BLE 网络降级** | Wi-Fi 挂了仍能聊，消除体验断点 | 工程成本可控，适合作为卖点 |
| **Realtime 拟人对话** | 首包数百毫秒、可打断 | 高客单产品可评估 Omni / Audio-3.0 Realtime |

**逻辑链**：三路同步保底线 → 记忆日记做活人感 → 情感黏性 → 才可能谈订阅。在此之前推订阅，难以越过「摆件为什么要月费」的门槛。

> ⚖️ **合规边界**（《人工智能拟人化互动服务管理暂行办法》，2026-07-15 施行）：桌宠作为「持续性情感互动服务」直接适用。不得以诱导沉迷依赖为服务目标；须算法备案、AI 身份标识、超 2 小时提醒；面向未成年人另有虚拟亲密关系禁令与未成年人模式。详见 [05-faq.md](./05-faq.md) E 节与根目录 [faq.md](../../../faq.md) Q22.1。

## 二、形态与客户画像

### 2.1 四种形态

| 形态 | 典型 BOM 量级 | 客单参考 | 关键卖点 |
|---|---|---|---|
| 工位伴侣（极简屏 + 少舵机） | 60–120 元 | 199–399 元 | 设计感、不打扰、插电即用 |
| 表情屏桌宠（屏 + 2–4 舵机） | 80–180 元 | 299–699 元 | 表情丰富、语音动作同步 |
| 充电头 / 手机复用屏（Looi 路线） | 极低（复用手机） | $100–200 众筹档 | 软件定义、硬件极简 |
| 智能毛绒（有动作 / 灯效，可无独立屏） | 70–150 元 | 299–799 元 | IP 形象 + 触摸反馈 |

### 2.2 三类客户

| 类型 | 特征 | 适合路线 |
|---|---|---|
| 设计 / 潮玩创业团队 | 强工业设计或 IP，出货量级偏小 | 轻～中硬件溢价，重表情素材与人设 |
| 玩具 / 毛绒厂升级 | 有模具与渠道，缺 AI 链路 | 在存量毛绒上加舵机 / 灯效 + 标签链路 |
| 礼品 / 文创 / 企业定制 | 节日、年会、工位礼品 | 插电工位伴侣，控 BOM、控云端年费 |

### 2.3 与玩具陪伴的边界

| 判断维度 | 走玩具陪伴 [`03`](../03-toys-companion/) | 走桌宠（本品类） |
|---|---|---|
| 输出通道 | 主要是语音 | 语音 + 表情 / 动作 / 灯光至少一路 |
| 摆放场景 | 床头、随身、挂件 | 桌面固定位为主 |
| 客单心智 | 玩具 / 潮玩 | 摆件 / 伴侣 / 礼品 |
| 技术增量 | ASR + LLM + TTS + 角色 | 再加标签嵌入式三路同步 |

## 三、订阅可行性：已知未跑通

**结论：截至当前版本，公开市场未见跑通的桌宠 AI 月度订阅案例。**

已知尝试与观察：

1. **解锁动作 / 表情包** → 用户认为买硬件时就该带齐，续费意愿弱
2. **日记 / 记忆会员** → 有信号，但单点功能撑不起月费心智
3. **按 token / 按时长** → 用户难以理解，桌宠场景已被市场淘汰
4. **海外参照**：Vector 等产品历史上更多是硬件 + 云服务捆绑或买断式云，并非「聊天月费」样板

**建议**：

- 不押注订阅 ARPU；云端成本按「轻度 20 轮/天、qwen-flash / plus」测算后摊进售价（见 [`03-cost.md`](./03-cost.md)）
- 架构上预留记忆日记与用户画像数据链路，待活人感成熟后再考虑「日记备份 / 多设备同步」类年费包装（类似海外「宠物保养会员」思路，而不是「聊天月费」）

## 四、毛利结构（量级）

仅作行业一般性陈述，非任何具体厂商数据：

```
轻硬件桌宠（零售 399 元档）示意：

  零售价：              399 元
  - 渠道与营销：       80–120 元
  - 硬件 BOM + 组装：  80–150 元
  - 首年云端 AI 摊销：  5–15 元
  - 认证 / 售后预提：   10–20 元
  ─────────────────────────────
  品牌侧毛利空间：     约 100–200 元量级（强依赖渠道结构）
```

三个结论：

1. 云端 AI 不是毛利杀手——控在十几元/台/年以内即可被 399 元档吸收
2. 真正吃毛利的是渠道与开模；小批量开模会把 BOM 从 80 元抬到 150+ 元
3. Realtime 全双工链路单位时长成本显著高于三段式，只适合高客单或日活极高的旗舰 SKU

## 五、决策树：要不要做桌宠

```
有没有「表情 / 动作」差异化？
  ├─ 没有 → 做纯语音玩具，走 03-toys-companion，不要硬上桌宠
  └─ 有
       ├─ 有没有 IP 或工业设计？
       │    ├─ 没有 → 轻硬件 + 开源参考（小智类）快速验证，客单压在 300 元档
       │    └─ 有 → 中硬件，客单 500–1500，把表情素材与人设做成壁垒
       └─ 目标用户是否含未成年人为主？
            ├─ 是 → 先做拟人化互动办法适用性评估与未成年人模式
            └─ 否（工位 / 成年潮玩）→ 仍需 AI 标识与防沉迷提醒，但约束相对轻
```

## 六、品类适配速查

| 问题 | 建议 |
|---|---|
| 只要会说话 | 不要选桌宠，选玩具陪伴 |
| 要三路同步、像「活物」 | 选桌宠，标签嵌入式方案 C |
| 要极致低延迟拟人对话 | 高客单评估 Omni / Audio-3.0 Realtime + Runtime Host |
| 要多 Agent / 控全家设备 | 选 Agent 硬件，不是桌宠 |
