## A. 方案选型（Which one to use）

**A1：百炼「物理世界感知 Agent」和 OSS「AI 内容感知」到底该选哪个？**

一句话选型——

- **单独摘要场景**（事件帧 Caption、告警二次确认、AI 相册标签）：选 **百炼 · 物理世界感知**，计算缓存后整体性价比更高。
- **视频本身存储在 OSS，或带有自然语言检索、每日总结、一键成片等需求**：选 **OSS · AI 内容感知**。

两者互补，不冲突。可参考 [`02-solution.md`](./02-solution.md) 的方案总览对比表。

**A2：能不能组合用？**

能。典型链路：设备端抽帧 → 百炼实时生成 Caption → 帧 + Caption 写入 OSS → 被 AI 内容感知索引 → App 支持后续检索 / 摘要 / 剪辑。这样一份数据同时具备"实时告警"和"事后回查"两种能力。

**A3：Qwen-VL 视觉模型在这套方案里的定位？**

Qwen-VL 是**底层视觉模型**，可以直接被业务代码 `chat.completions` 调用做通用视觉理解。百炼「物理世界感知 Agent」是**基于 Qwen-VL 面向 IPC 场景做过 Agent 编排与提示词优化**的托管服务，输出结构化 JSON，开箱即用；如果要做深度自定义（自研 Prompt / 微调）可以直接调 Qwen-VL。

**A4：云端 AI 和边缘 AI（如 Eufy HomeBase）怎么权衡？**

| 维度 | 云端 AI | 边缘 AI |
|---|---|---|
| 隐私 | 数据上云需合规声明 | 数据不出户，用户信任度高 |
| 单台硬件成本 | 低 | 高（HomeBase / AI Core） |
| 单台运营成本 | 有月度调用费用 | 近零 |
| 能力天花板 | 高（可用最新大模型） | 受端侧算力限制 |
| 迭代节奏 | 快（云端更新即生效） | 慢（OTA / 硬件升级） |
| 商业模式 | 云存 + AI 订阅 | 硬件买断，"No Monthly Fee" |

结论：家用大众市场偏云端订阅，隐私敏感/欧美中高端市场偏边缘。可参考 [`04-cases.md`](./04-cases.md) 里 Anker eufy 的案例。

**A5：端云协同架构应该怎么切？**

一级过滤放端侧，二级精分析放云端：

- **端侧**：移动检测、人形/宠物/车辆等基础识别；婴儿哭声、笑声检测等低延迟需求场景；对大模型理解需求不高但对隐私要求高的场景；放端侧。
- **云端**：对被端侧触发的事件片段做大模型 Caption / 摘要 / 检索。

## B. 接入实操（How to integrate）

**B1：百炼多模态应用创建时，哪些开关必须关掉？**

创建"多模态交互应用（全能版）"后：

- 关闭：**语音交互**、**对话承接语**、**知识库**、**联网搜索**、**长期记忆**
- 删除：**全部指令、插件、MCP 服务**
- 只保留：**意图识别、文本模型、物理世界感知 Agent**

具体步骤见 [`02-solution.md`](./02-solution.md#step-2关闭无关功能)。

**B2：API-KEY 和 APP-ID 分别从哪里拿？**

- API-KEY：百炼控制台 → 右上角个人中心 → API-KEY 管理
- APP-ID：百炼控制台 → 多模态开发套件 → 我的应用 → 应用卡片上直接复制

APP-ID 必须**发布应用**后才生效，未发布状态下调 API 会 404。

**B3：图像 / 视频 / image_list 三种输入格式怎么选？**

| 输入 | 何时用 | 备注 |
|---|---|---|
| `format=image` + 单张 | 事件帧摘要、单帧告警二次确认 | 最省 tokens |
| `format=image` + 多张 | 一次分析一组连拍 | 支持多图同时传入 |
| `format=video` + 单/多 mp4 | 完整短片段分析 | 多视频会被拼接处理 |
| `format=video` + image_list | 想按自定义节奏抽帧 | **至少 4 张且为偶数**，`frame_enabled=true` |

`type` 支持 `url`（必须 HTTPS）和 `base64`（累加不超过 10 MB）。

**B4：显式缓存需要自己实现吗？**

不需要。百炼服务侧对物理世界感知 Agent **默认自动做显式缓存**：每一条请求都会带上缓存标记，第一次请求写入，后续请求命中即直接复用缓存跳过重复推理。固定 system prompt、Agent 配置、重复场景帧都能受益。开发者只需正常构造请求即可享受延迟和 tokens 成本下降。

**B5：SSE 返回怎么解析？为什么只看 `finished=true` 的包？**

物理世界感知 Agent 走的是流式对话协议，中间会推多个 `finished=false` 的分片包，但**只有 `finished=true` 的最终包**含完整结构化结果。解析时：

1. 只处理 `finished=true` 的包
2. 取 `output.text`，它是**JSON 字符串**，需要二次 `JSON.parse()`
3. Tokens 用量在 `output.extra_info.agent_info.ext_params.usage`，字段名为**驼峰**：`inputTokens` / `outputTokens` / `totalTokens`

**B6：OSS AI 内容感知支持哪些地域？海外要怎么开？**

当前支持：华北 2/3、华东 1/2、华南 1、西南 1、**新加坡、美国（弗吉尼亚）**。新加坡和美国需**提工单开通**。其他海外地域暂不支持，出海项目可先把数据回传国内 Bucket 索引，App 侧再回传检索结果。

## C. 成本与配额（How much & how to control）

**C1：单张图片消耗多少 tokens？分辨率怎么影响？**

物理世界感知（走 Qwen-VL 底层）按像素计费：

```
image_tokens ≈ width × height ÷ 32 ÷ 32
```

- 640 × 360 ≈ 225 tokens/张
- 1280 × 720 ≈ 900 tokens/张
- 1920 × 1080 ≈ 2025 tokens/张

**推荐 IPC 场景走 640×360 或更低，性价比最高**。开启 `high_resolution` 会拉高上限，非必要不开。

**C2：单台设备一个月的 AI 成本大概能压到多少？**

轻量场景（低频抽帧、只做事件摘要）参考值约 **0.022 分/次调用**（详见 [`03-cost.md`](./03-cost.md)）。按不同调用频次估算：

- 每天 10 次事件：月成本 ≈ 6.6 分/台
- 每天 30 次事件：月成本 ≈ 2 毛/台
- 每天 100 次事件：月成本 ≈ 6.6 毛/台

**注意**：以上未计入服务器、带宽、存储、运维等运营成本，仅为大模型侧调用成本。

**C3：OSS AI 内容感知的国内单价参考？**

- **图片**：1.81 元/千张
- **视频**：0.0236 元/分钟

配合数据索引费用 + API 请求费用三段计费，详见 [`03-cost.md`](./03-cost.md#4-oss-ai-内容感知成本测算)。

**C4：大规模上量有啥控本手段？**

五个抓手：

1. **文件过滤规则**：OSS 开启时最多配 5 条（前缀、大小、LastModifiedTime、ObjectTag），避免全 Bucket 索引。收益 5~10 倍。
2. **端云协同**：端侧更精细的事件检测，或在端侧对视频做视频抽帧后上传图片给大模型。
3. **合理抽帧**：对事件视频采用 dhash 或其他智能抽帧策略，如 15 秒视频抽 ~3 帧，而非 1 秒 1~2 帧。
4. **分辨率下沉**：640×360 起步。相比原图上传，收益 4~9 倍。
5. **显式缓存 + 摘要聚合**：显式缓存服务端自动做；业务侧按小时/事件聚合摘要，避免每帧一调。

## D. 产品与场景（What can I build）

**D1：婴儿监护器、宠物摄像头是不是同一套方案？**

架构一样（IPC + 百炼 / OSS），但 Prompt 和 UI 卡片形态差异化：

- 婴儿监护：默认 Prompt 关注睡眠状态 / 翻身 / 哭闹；日报做"今日宝宝精彩瞬间"
- 宠物摄像头：关注异常吠叫 / 打斗 / 跳桌；日报做"今日宠物趣闻"

这两个方向对"AI 找回放"和"自动摘要"诉求最强，用户付费意愿明显高于普通家用 IPC。

**D2：户外门铃和家用 IPC 走同一套方案吗？**

底层一样，Prompt 和事件模型不同：

- 户外门铃：识别陌生人、快递员、可疑徘徊；卡片强调"何时何人在门口"
- 家用 IPC：识别宠物、小孩、家人日常活动；卡片强调"今天家里发生了什么"

两者的告警策略也不同：门铃偏"实时推送 + 事件卡片"，家用偏"每日汇总 + 按需检索"。

**D3：可穿戴 AI 相机（如 Looki）能复用 IPC 这套方案吗？**

**能，且几乎无缝**。可穿戴设备的痛点是"拍了一堆素材没人剪"，正好命中 OSS AI 内容感知的能力矩阵：中文化描述 + 自然语言检索 + 一键成片。区别在于：

- 触发方式：可穿戴通常是**主动全量记录**，端侧无过滤，直接写入 OSS
- UI 形态：以时间线 / 日 vlog 为主，弱化告警卡片
- 成本模型：调用量比家用 IPC 高一个数量级，需要更强的过滤 + 聚合

**D4：家用 IPC 和商用 IPC 的商业模式差异？**

| 维度 | 家用 IPC | 商用 IPC |
|---|---|---|
| 付费主体 | 个人 | 公司 / 政企 |
| 决策链路 | 感性、单人 | 理性、多人 |
| 计费方式 | 月度订阅 | 项目 + API 接入 |
| 部署形态 | 云端为主 | 云 / 边 / 私有化混合 |
| 定价锚 | 云存 + AI 增值 | 按事件量 / 按摄像头 / 按并发 |

家用适合走"AI 订阅升级"，商用适合走"事件分析报告 + API 接入企业系统"。

**D5：想做 ODM / OEM，头部方案商能借力吗？**

可以。参考 [`04-cases.md`](./04-cases.md)：

- 技威 Yoosee：VSaaS + 硬件分润模式，双大模型后端（豆包 + 千问）
- 广州九安 Juan：ODM + JuanCloud 平台运营（B2B2C SaaS 订阅），已搭载千问大模型
- 深圳乔安 JOOAN：产品线明确标注"AI 大模型摄像头"，具备事件摘要能力

小品牌与其自己从零接大模型，不如通过头部方案商拿"打包 AI 能力"的方案更快落地。

## E. 订阅与商业化（How to sell）

**E1：存量云存用户做 AI 升级 vs 从零拉新，哪个先跑？**

**优先做存量升级**。已知跑通的路径都是：先在存量云存包月用户中推 AI 升级套餐，用户已有付费习惯 + 数据留存，转化门槛低。零基础拉新做 AI 订阅目前**未跑通**明确的规模化案例。

**E2：免费试用 vs 直接卖，怎么切？**

多数已跑通案例走**先免费试用 1~4 个月**再转付费的路径：

- 免费期养成"AI 找回放""每日摘要"的使用习惯
- 试用结束前 1~2 周做"再不订阅就用不了"的提醒
- 首月大幅折扣或首年优惠

直接标价卖 AI 订阅需要极强的差异化功能和市场教育，未见广泛跑通。

**E3：中小厂需要具备什么条件才适合上 AI 套餐？**

三个前提条件都成立才有意义：

1. 有一定量级的存量云存用户基数（App 自有账号体系是刚需）
2. 已有云存付费转化率跑通（说明用户已认可"云存"这个产品形态）
3. 有能力做"AI 试用 → 转化"的运营链路（Push、App 引导、客服话术）

**E4：出海对标 Ring / Nest / Arlo，差异化怎么做？**

参考现有跑通打法：

- **中文场景差异化**：Ring / Nest 主要面向英语市场，AI 摘要对中文语义理解偏弱
- **本地化事件类型**：欧美关注"陌生人 / 包裹 / 车辆"，东南亚 / 中东场景需求不同
- **合规差异化**：欧美 GDPR 严格，边缘 AI 架构（如 Eufy 路线）在中高端市场吃香
- **性价比差异化**：欧美 IPC AI 订阅月费 $3.99~$8，国内厂商可用更强的性价比切入中端

## F. 合规与隐私（Legal & privacy）

**F1：AI 摘要会涉及隐私问题吗？如何设计合规？**

会涉及。摘要文本可能包含家人活动、生活习惯等敏感信息。建议：

- 摘要默认只对账号主人可见，账号内多设备共享需二次授权
- 摘要文本加密存储
- App 提供"关闭 AI 摘要"开关，并在用户协议中明示 AI 处理范围
- 支持用户随时删除摘要（同步删除向量索引）

**F2：人脸识别合规怎么处理？**

国内业务遵守《个人信息保护法》《人脸识别技术应用安全管理规定》：

- **默认不做人脸识别**，只做"人形检测"和"陌生人/熟人"二元区分
- 如需人脸识别（门禁、家人区分），必须**用户明确授权**并可撤回
- **不对未授权陌生人做长期跟踪或数据留存**
- 出海项目额外检查目的地隐私法（GDPR / CCPA / 各国生物识别法）

**F3：服务器端会留存视频用于训练吗？**

阿里云 OSS 数据归客户所有，平台不会保留或用于训练；AI 内容感知生成的描述 / 摘要存放在客户自己的 Bucket 元数据中。百炼多模态服务侧短期缓存用于显式缓存加速，可在合同中约定数据处理边界。**建议在客户 App 用户协议中同步声明**。

**F4：跨境业务（出海日韩/东南亚/欧美）合规有哪些坑？**

四个必查项：

1. **服务地域**：新加坡 / 美国 Bucket 需提工单开通，其他海外区域暂不支持
2. **数据存储地域**：欧盟数据必须落地欧盟；日韩、印度尼西亚、越南等地有本地数据留存要求
3. **合同条款**：出海合同必须明确数据存储 Region、跨境传输条款、AI 处理边界
4. **特殊监管**：欧盟 AI Act、加州 CCPA、部分国家对生物识别有额外报备要求
