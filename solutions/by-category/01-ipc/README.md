## 品类概述

- 消费级 IP 摄像头 + AI 大模型应用能力
- 形态：家用（云台机 / 枪机 / 电池机）、户外门铃、可穿戴拍摄相机、边缘 AI 一体机等
- 客单价：设备 50 ～ 500 元；叠加 云存储 / AI 服务订阅

## 商业化现状（公开信息观察）

- **是 AI 硬件中订阅模式已知跑通的代表品类**：基于「100 段视频懒得自己看」的痛点，AI 摘要 + 语义检索 + 事件推送形成付费场景。
- **存量云存用户是最佳转化池**：已有付费习惯的用户对 AI 增值服务接受度高。
- **核心差异是「自然语言搜视频」**：摆脱按时间线翻找，改成「找昨晚 9 点小孩在沙发上跳的片段」。

> 📊 详细市场判断 → 见 [01-business.md](./01-business.md)

## 推荐架构（千问大模型版本）

两条接入路径，按需选用或组合：

| 路径 | 能力定位 | 典型场景 |
|---|---|---|
| **百炼 · 物理世界感知 Agent** | 结构化 Caption（object / action / event / description / title） | 事件帧摘要、AI 相册标签、告警二次确认 |
| **OSS · AI 内容感知** | 自然语言检索、每日总结、一键成片、事件告警 | 事后回查、时间线聚合、智能剪辑 |

> 🛠️ 完整接入步骤 → 见 [02-solution.md](./02-solution.md)

## 成本与计费

- **BOM 增量**：零（只要摄像头能将图片 / 视频上传到 OSS 即可）
- **按量计费**：数据索引 + AI 模型费用
- **报价口径**：月度订阅（已知跑通的市场范围 5 ～ 9.9 元/月，包年折扣）

> 💰 详细测算 → 见 [03-cost.md](./03-cost.md)
