## 一、品类利润逻辑

### 1.1 卖的是「工位替代 / 场景交付」，不是「AI 聊天包」

具身购买心智接近**产线设备 / 巡检资产 / 科研平台**：客户为「少雇一个人、少一次危险巡检、跑通一个固定任务」付费。大模型是降低示教与换线成本的杠杆，不是单独可卖的订阅 SKU。

| 路线 | 加价逻辑 | 谁在做 | 备注 |
|---|---|---|---|
| **协作臂 + 语言抓取（工业主流）** | 臂 + 末端 + 集成 → 项目报价 | UR / 遨博 / 节卡等 + 视觉方案商 | ROI 可算；VLA 做换 SKU 泛化 |
| **四足巡检 / 安防** | 本体 + 载荷传感 + 运维 | 宇树 Go2 系、工业四足 | 场景验证中；软件与站点部署吃毛利 |
| **人形科研 / 演示** | 本体溢价 + EDU SDK | 宇树 G1、Figure 等 | 早期；安全与任务泛化未跑通消费订阅 |
| **开源低成本臂验证** | BOM 低 → 研发自用 | SO-ARM / LeRobot 生态 | 适合算法验证，不是量产交付 |

### 1.2 当前阶段：硬件 / 项目买断 + 算力内嵌

公开市场观察：

```
边缘 Orin / 工控机一次性投入
  + 云端偶发规划 Token（可忽略或摊进服务合同）
  → 集成商按项目或按工位报价
  → 用户不接受「机械臂还要月费聊天」
```

**订阅已知未跑通**（消费品类意义上的 AI 月费）。可行的是：维保合同、远程运维、地图 / 策略更新年费——包装成设备保养，而不是 token 账单。

### 1.3 下一阶段：统一动作表征与数据飞轮

| 能力 | 作用 | 现状 |
|---|---|---|
| **混合 VLA** | 语言泛化 + 运控安全门 | 推荐默认架构，见 [`02-solution.md`](./02-solution.md) |
| **跨本体动作空间** | 一套策略迁多机型 | RobotManip 类 80 维表征在公开资料中推进 |
| **世界模型合成数据** | 降实机试错成本 | RobotWorld / 仿真管线；仍是瓶颈 |
| **零样本导航** | 少标定进场 | Go2 + 单相机等公开演示可参考 |

**逻辑链**：固定场景跑通 ROI → 语言换线降示教 → 数据飞轮降成本 → 才可能谈平台订阅。在此之前推「机器人 ChatGPT 会员」，难以越过采购心智。

## 二、形态与客户画像

### 2.1 三种本体形态

| 形态 | 自由度 | 客单参考（公开量级） | 大模型切入点 | 商业化阶段 |
|---|---|---|---|---|
| 协作臂 | 6–7 DOF | 臂本体约 $6k–$40k+；整单元更高 | 语言 → 抓取 / 装配规划 | ⭐⭐⭐ 已规模落地 |
| 四足 | 12+ DOF | Go2 Air/Pro/X 约 $1.6k–$4.5k 起（未含税运） | 语言 → 导航 + 巡检任务 | ⭐⭐ 场景验证中 |
| 人形 | 20–40+ DOF | G1 官宣约 $13.5k 起；EDU 报价制 | 全任务泛化（远期） | ⭐ 早期探索 |

> 价格以厂商官网 / 公开渠道为准，随配置与区域浮动。详见 [`03-cost.md`](./03-cost.md) 与 [`awesome/.../09-embodied.md`](../../../awesome/commercial-products/by-category/09-embodied.md)。

### 2.2 三类客户

| 类型 | 特征 | 适合路线 |
|---|---|---|
| 工厂 / 物流集成商 | 要 ROI、要 CE/ISO、要稳定节拍 | 协作臂 + 混合 VLA；先固定工位 |
| 巡检 / 安防 / 园区 | 要移动覆盖、要远程运维 | 四足 + Nav；载荷与通讯是关键 |
| 高校 / 算法团队 | 要 SDK、要数据闭环 | EDU 人形 / 开源臂；先仿真再实机 |

### 2.3 与桌宠 / 玩具的边界

| 判断维度 | 走桌宠 / 玩具 | 走具身（本品类） |
|---|---|---|
| 输出 | 表情 / 短舵机 / 语音 | 移动、抓取、力矩级物理交互 |
| 失败代价 | 体验差 | 碰撞、伤人、产线停线 |
| 客单心智 | 潮玩 / 礼品 | 资本开支 / 科研设备 |
| 技术增量 | ASR+LLM+TTS(+标签) | 感知融合 + VLA + 运控安全 |

## 三、订阅可行性：已知未跑通（消费心智）

**结论：截至当前版本，公开市场未见跑通的「具身 AI 月度聊天订阅」样板。**

已知观察：

1. **工业** → 项目交付 + 维保年费；采购按 CAPEX/OPEX 设备口径
2. **四足消费级** → 硬件买断为主；高级功能多一次付费或 App 内购，非稳定 ARPU
3. **人形** → 演示与试点合同；Figure 等商业部署偏 B2B 试点，非 C 端订阅
4. **云端 Token** → 可计量，但客户不愿单独看见「机器人 token 账单」

**建议**：

- 不押注聊天订阅 ARPU；云推理按日均规划次数测算后摊进项目毛利（见 [`03-cost.md`](./03-cost.md)）
- 架构预留策略热更新与远程诊断，待多站点部署后再包装「运维年费」

## 四、毛利结构（量级）

仅作行业一般性陈述：

```
工业单工位示意（协作臂语言抓取）：

  项目报价：           15–40 万量级（含臂/视觉/集成/培训）
  - 本体与传感：       5–20 万
  - 集成与软件：       4–12 万
  - 认证与围栏：       1–5 万
  - 首年云/远程预提：  可忽略～数千
  ─────────────────────────────
  集成商毛利：         强依赖调试周期与换线次数
```

三个结论：

1. Token 几乎不是毛利杀手；**调试人天与安全认证**才是
2. VLA 的商业价值是**缩短换 SKU / 少示教**，不是替代运控
3. 人形消费故事很响，但近期现金流仍在工业臂与四足场景

## 五、决策树：要不要做具身

```
任务是否必须「动物理世界」？
  ├─ 否 → 不要做具身；做 IPC / 眼镜 / 桌宠等
  └─ 是
       ├─ 环境是否结构化、ROI 是否可算？
       │    ├─ 是 → 协作臂 + 混合 VLA，先一个工位闭环
       │    └─ 否（家庭无序）→ 谨慎；先做巡检四足或科研验证
       └─ 是否需要人形外观？
            ├─ 仅为融资叙事 → 先臂 / 四足跑通，再谈人形
            └─ 确有双臂操作刚性需求 → EDU / 试点，预留 6–18 月安全与集成
```
