## 一、核心洞察

具身技术栈 = **语言规划** + **VLA 工具** + **运控安全门** + **感知融合**

| 路线 | 泛化 | 部署 | 安全 | 适用 |
|---|---|---|---|---|
| 传统 SLAM + 路径规划 | 低 | 中 | 高 | 固定产线 |
| VLA 端到端直驱关节 | 高 | 高算力 | 低（黑箱） | 研究 / 仿真 |
| **混合方案（推荐）** | 高 | 中 | 高 | 工业 + 服务 |

**推荐默认**：VLA / LLM 只输出**离散技能或增量位姿目标**；速度、力矩、碰撞、禁区由底层 Safety Gate 强制执行。

---

## 二、推荐分层架构

```
┌────────────── 交互 / 业务层 ──────────────┐
│  语音 / App / MES 工单 → 自然语言任务      │
└──────────────────┬───────────────────────┘
                   ▼
┌────────────── 规划层 ────────────────────┐
│  Qwen / Qwen-Omni：意图解析、任务分解、评判 │
│  输出：有序技能列表（nav / pick / place …） │
└──────────────────┬───────────────────────┘
                   ▼
┌────────────── VLA 工具层（Qwen-Robot Suite）─┐
│  RobotNav     语言 → 导航轨迹 / 目标搜索      │
│  RobotManip   语言+视觉 → 操作动作（统一表征）│
│  RobotWorld   预演 / 合成数据 / 轨迹可行性    │
└──────────────────┬───────────────────────┘
                   ▼
┌────────────── Safety Gate（必须）──────────┐
│  速度分区 · 力矩上限 · 工作空间围栏 · 急停   │
│  人类协作臂：ISO 10218 / ISO/TS 15066 约束  │
└──────────────────┬───────────────────────┘
                   ▼
┌────────────── 执行层 ────────────────────┐
│  臂控制器 / 四足 SDK / 人形运控 · 力传感闭环 │
└──────────────────────────────────────────┘
```

## 三、Qwen-Robot Suite 怎么用（品类视角）

| 模型 | 定位 | 输入 → 输出 | 何时调用 |
|---|---|---|---|
| **RobotNav** | 行动入口 | 语言 → 导航 / 搜索 / 追踪 | 移动底盘、四足进场 |
| **RobotManip** | 交互基石 | 语言+相机 → 操作动作 | 抓取、放置、插接 |
| **RobotWorld** | 无限世界 | 语言+视觉 → 未来预测 | 仿真预演、合成数据、高风险动作前评估 |

统一原则（来自公开技术说明）：

- **语言优先接口**：上层 Agent 把三者当工具，而不是绑死单一端到端网络
- **跨本体**：Manip 侧公开资料强调统一状态-动作空间（约 80 维）与相机系增量位姿
- **规模参考**：Nav 2B–8B；Manip 约 4B VL + 动作头；World 偏云端重模型

> 训练小时数、基准分、博客链接 → [`05-qwen-robot.md`](../../by-solution/05-qwen-robot.md)

## 四、典型场景集成

### 4.1 工业分拣（语言换 SKU）

```
语音/工单「把红色零件放到 B 区」
  → LLM 分解：locate(red_part) → grasp → navigate_bin(B) → place
  → Manip：视觉定位 + 抓取轨迹候选
  → Safety Gate：限速、防碰撞、夹爪力上限
  → 执行 + 力/视觉确认 → 失败则重试或人工接管
```

### 4.2 四足寻物巡检

```
「去充电桩附近找黄色安全帽」
  → Nav：指令跟随 / 目标搜索
  → 单相机或补盲雷达（按本体配置）
  → 到点后可选 Manip（若带臂）或仅上报坐标拍照
```

公开参考：宇树 Go2 零样本部署 Qwen-RobotNav（单低分辨率相机寻物导航）——见方案文「已验证落地」。

### 4.3 仿真预演（降 Sim-to-Real 成本）

```
候选动作序列 → RobotWorld 预测 → 过滤碰撞/不稳定 → 再下发实机
```

## 五、意图路由协议（对接 demo）

端侧 / 网关把规划结果落成**结构化计划**，便于审计与安全门拦截。最小 JSON 约定：

```json
{
  "utterance": "把桌上的螺丝放到左边盒子",
  "skills": [
    {"name": "locate", "args": {"object": "screw", "area": "table"}},
    {"name": "grasp", "args": {"object": "screw", "max_force_n": 15}},
    {"name": "place", "args": {"target": "box_left"}}
  ],
  "risk": "medium",
  "requires_confirm": false
}
```

安全门规则示例：

| 规则 | 行为 |
|---|---|
| `max_force_n` 超阈 | 改写或拒绝 |
| 技能 ∈ `{strike, throw, chase_human}` | 硬拒绝 |
| `risk=high` | 强制人工确认 |
| 未知技能名 | 拒绝并回落「请改述」 |

可运行实现：[`demo/vla-intent-router/`](./demo/vla-intent-router/)。

## 六、算力与部署

| 平台 | 量级 | 建议 |
|---|---|---|
| RK3588 | ~6 TOPS NPU | Nav 小模型 / 轻量检测 |
| Jetson Orin NX 级 | ~100 TOPS | Manip 实时候选 |
| 工控机 + GPU | 可扩展 | 产线多臂共享推理 |
| 云端 | Token / 时序 | World 预演、重规划、训练 |

**选型口诀**：RobotNav 小规格可边缘；RobotManip 建议 Orin 级；RobotWorld 默认云端。

---

## 七、关键约束与应对

| 约束 | 说明 | 应对 |
|---|---|---|
| 安全围栏 | 协作臂 ISO 10218 等 | 力矩限制 + 速度分区 + 急停硬件 |
| 延迟 | 抓取闭环常要求 &lt;100ms 级 | 边缘推理；云端只做低频规划 |
| Sim-to-Real | 仿真策略实机衰减 | Domain Randomization + World 合成数据 |
| 多本体 | 动作空间不同 | 统一表征 + 每本体标定层 |
| 数据合规 | 厂区影像外传 | 边缘优先；脱敏上传 |

---

## 八、MVP 落地顺序（4–8 周量级）

1. **周 1–2**：单工位传统视觉抓取跑通（无 VLA）+ Safety Gate 骨架  
2. **周 3–4**：接入语言 → 技能路由（可用规则 / 小模型，见 demo）  
3. **周 5–6**：Manip / Nav 替换其中一两个技能；记录失败 case  
4. **周 7–8**：World 预演或仿真回归；整理示教数据闭环  

不要第一步就做人形全身 VLA。
