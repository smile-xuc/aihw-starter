> 本目录用于存放 AI 眼镜及多模态交互套件相关的可运行示例代码。
> 当前为占位版，欢迎社区贡献最小可运行 demo。

## 计划包含的 demo

- [ ] **`suite-linux/`** — 多模态交互开发套件 Linux Demo 集成示例
- [ ] **`suite-rtos/`** — RTOS（FreeRTOS/AliOS Things）平台移植示例
- [ ] **`device-command/`** — 设备指令配置与端侧解析示例
- [ ] **`vision-vl/`** — 摄像头拍摄 + Qwen-VL 物体识别 demo
- [ ] **`subtitle-ar/`** — AR 字幕实时渲染（光波导/Birdbath 方案）
- [ ] **`learning-machine/`** — 学习机场景模板示例
