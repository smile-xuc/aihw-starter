## 一、日活敞口模型

眼镜是全天佩戴设备，云端成本由使用行为决定，先建立敞口模型再做功能定价：

```
月度云端成本 = Σ（各功能：日均触发次数/时长 × 单次/单位成本 × 30）

低频按次功能（可默认开放）        高频按时长功能（需功能包承接）
├─ 语音问答：次/天 量级          ├─ 同声传译：分钟/天 量级
├─ 一看即懂：次/天 量级          ├─ 实时音视频：分钟/天 量级
└─ 拍照记录：次/天 量级          └─ 实时字幕：小时/天 量级
```

**结论先行**：

1. 按次功能（问答/看懂）轻度使用每台每月**个位数元**，可摊入硬件价
2. 按时长功能（同传/omni 实时/字幕）重度使用每台每月**数十元**，必须用功能包/订阅承接，不能默认全量开放
3. 敞口控制的第一手段在端侧：VAD 前置、按需触发、图片压缩（见 [02-solution.md](./02-solution.md) 第六节）

## 二、BOM 分层（三形态）

| 形态 | 关键增量件 | BOM 参考区间 | 说明 |
|---|---|---|---|
| 音频眼镜 | 麦克风阵列 + 定向扬声器 + 蓝牙音频 SoC（兼跑端侧唤醒） | 200–500 元 | 芯片结构接近 TWS 耳机方案 |
| 拍照眼镜 | + 摄像头模组（12MP 级）+ 低功耗 Wi-Fi/蓝牙/ISP 芯片组合 | 500–1200 元 | 入门走泰芯级 Wi-Fi/ISP + 杰理蓝牙；高端走恒玄 BES2800 + 独立 ISP；旗舰走高通 AR1 + 协处理，芯片组合是 BOM 主要变量之一 |
| AI 显示眼镜 | + 单绿 Micro-LED 光机 + 衍射光波导 + 高通 AR1 级主控 | 1000–2000 元 | **显示部分单眼约增加 500 元**；双目显示则翻倍；主控档位高于拍照档 |

> BOM 为公开拆解报告与行业报道的估算区间。芯片组合详见 [02-solution.md](./02-solution.md) 1.4 节。整机重量每增加 10g 对佩戴时长的影响大于任何单项功能，轻量化投入优先级高于堆料。

## 三、云端成本结构（按功能）

| 功能 | 计费维度 | 用量特征 | 成本量级判断 |
|---|---|---|---|
| 语音问答 | LLM token + ASR 时长 + TTS 字符 | 次数少、单次短 | 低，摊入硬件价 |
| 一看即懂（拍照识别） | VL token（图片为主）+ TTS | 图片 token 占大头 | 中，压缩图片直接降本 |
| 同声传译 | livetranslate 按时长 | 单次使用即数十分钟 | 高，功能包承接 |
| 实时音视频（omni） | 按时长（音频+视频通道） | 视频帧率决定倍率 | 最高，旗舰体验按需触发 |
| 会议听记 | 听悟按音频时长（离线转写更低） | 低频长时 | 中，离线链路可控 |

三个降本要点：

1. **图片压缩是视觉功能的第一降本手段**：分辨率降半，图片 token 约降 75%
2. **omni 视频帧率控制在 1 fps 上下**：帧率翻倍成本近似翻倍，体验增益递减
3. **听记走离线转写**：「会后出纪要」体验足够，成本显著低于实时转写

## 四、单台月度成本测算模板

```
用户画像假设：
  语音问答：______ 次/天 × 单次成本 → ______ 元/月
  一看即懂：______ 次/天 × 单次成本 → ______ 元/月
  同声传译：______ 分钟/天 × 时长单价 → ______ 元/月
  会议听记：______ 小时/月 × 转写单价 → ______ 元/月
  ────────────────────────────────────
  合计敞口：______ 元/月

对照：
  - 摊入硬件价可承受线：客单价 × 毛利率 ÷ 预期服役月数
  - 超出部分 → 划入功能包，由订阅/加购承接
```

典型参考量级（中等使用强度、公开口径估算）：

| 使用画像 | 月度云端成本量级 |
|---|---|
| 轻度（问答为主，偶尔拍照识别） | 几元 |
| 中度（每日识别 + 每周翻译/听记） | 十几元 |
| 重度（每日同传/字幕 30 分钟以上） | 数十元 |

## 五、报价口径

| 模式 | 适用 | 说明 |
|---|---|---|
| 按量付费 | 研发自主的品牌商 | 客户持 API-KEY，用量透明 |
| 功能包/Credit 包 | 同传、听记等高成本功能 | 预付费按量扣减，与 C 端功能包定价对应 |
| 套件 + 底层用量 | 走套件路线的客户 | 套件本身当前不额外收费，按底层模型用量计费 |
