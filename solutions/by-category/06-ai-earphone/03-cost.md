## 一、硬件 BOM 参考

以「真无线 AI 翻译耳机」为基准，批量约 1k–10k pcs 量级（相对普通 TWS 的**增量**更关键）：

| 组件 | 参考单价（元） | 说明 |
|---|---:|---|
| 蓝牙 SoC（含基础 DSP） | 15–45 | 与普通 TWS 同源；旗舰可上更高算力 |
| 麦克风（双麦 / 三麦 ENC） | 3–20 | 同传场景 ENC 比音乐耳机更敏感 |
| 骨传导麦（可选） | 8–25 | 开放式旗舰常见增量（讯飞等公开主打骨导+气导） |
| 喇叭 / 声学腔体 | 8–25 | 听译体验依赖清晰人声，不单靠低音 |
| 电池 + 充电盒 | 15–40 | 同传长会话推高续航诉求 |
| 天线 / RF | 2–8 | 稳定连接影响同传体验 |
| 外壳 + 结构 | 10–40 | 耳挂 / 开放式模具更贵 |
| PCB + 贴片 | 8–20 | — |
| **合计（整机）** | **约 80–200** | 不含认证与包装 |
| **相对普通 TWS 增量** | **约 5–40** | 麦阵 / 骨导 / RF / 认证 |

**插电无关**：耳机几乎全是电池形态；工程重点是 **VAD + 按需联网**，避免空闲推流烧续航与云端配额。

## 二、云端 AI 成本测算

### 2.1 Livetranslate（端到端同传）

> 口径来源（公开文档，2026-09 核对）：
> - 模型说明与单价：[qwen3.5-livetranslate-flash-realtime](https://help.aliyun.com/zh/model-studio/qwen3-6)
> - Token 换算：[实时语音翻译接入](https://help.aliyun.com/zh/model-studio/qwen3-5-livetranslate-flash-realtime)
> - 华北 2（北京）原价量级：输入音频 **40 元/百万 tokens**，输出音频 **160 元/百万 tokens**，输出文本 **100 元/百万 tokens**
> - 消耗规则（Qwen3.5）：输入音频约 **7 tokens/秒**，输出音频约 **12.5 tokens/秒**

粗算（仅音频、忽略源语言识别文本；**双向各说各听且近满负荷**时量级更高）：

| 场景 | 假设 | 成本量级 / 小时 |
|---|---|---|
| 单向听译（只听不说） | 输入满负荷 1h + 输出译文音频约 0.6–1h | 约 **1–8 元** 量级 |
| 双向同传 | 两路接近满负荷 | 约 **数元～十余元** 量级 |
| 轻度旅游（日均 20 分钟有效同传） | 按上表比例折算 | 约 **1–5 元/天** 量级 |

> ⚠️ 上表是**量级示意**，用于售价与时长包设计，不是报价单。活动价、免费额度、识别文本计费都会改变结果。以控制台与官方计费页为准：https://help.aliyun.com/zh/model-studio/billing-of-model-studio

### 2.2 三段式对话（ASR + LLM + TTS）

| 日均轮次 | 模型组合 | 月成本 / 台量级 | 适用 |
|---|---|---|---|
| ~10（轻度助手） | ASR + qwen-flash + cosyvoice flash | 1–3 元 | 白牌 / 轻量卖点 |
| ~30（中度） | ASR + qwen-plus + cosyvoice | 3–10 元 | 品牌 TWS AI |
| Omni-Realtime | 按音频时长 / token | 显著更高 | 仅旗舰全双工 |

### 2.3 与录音转写对照

会议转写 + 纪要按文件 / 流式 ASR + LLM，见 [`07-recorder/03-cost.md`](../07-recorder/03-cost.md)。耳机若附带「会后纪要」，建议单独计量，避免与同传配额混用。

## 三、售价与规模效应

| 量级 | 建议零售区间 | 备注 |
|---|---|---|
| 白牌跨境 | 99–299 元 | 必须硬封顶同传分钟 |
| 翻译旅行档 | $120–180（如 Timekettle M3 公开约 $119.99–$149.99） | 硬件溢价 + 可选离线包 |

## 四、成本结构概览

```
┌─────────────────────────────────────────┐
│  硬件 BOM + 贴片     25–45%             │
│  组装测试            8–12%              │
│  包装物流            5–10%              │
│  渠道营销            20–35%（差异最大） │
│  云端 AI（首年）     5–25%（同传敏感）  │
└─────────────────────────────────────────┘
```

**结论**：翻译耳机毛利敏感点在 **同传激活率 × 日均分钟**，不在芯片差价。技术侧用配额封顶、VAD 停传、会话级计量；商业侧用时长包 / 离线包对齐成本。

> 音频 token 换算与「同传 vs 闲聊」账单形态通识见 [primer/04 · Token 与计费](../../../primer/04-token-billing.md)。
