> **范围**：真无线 / 开放式 AI 翻译耳机、AI 对话耳机、兼带转写的会议耳机。

## 一、品类利润逻辑

### 1.1 卖的是「场景刚需」，不是「更好听」

AI 耳机的购买心智分三条线，加价逻辑不同：

| 路线 | 加价逻辑 | 谁在做 | 备注 |
|---|---|---|---|
| **翻译垂类（高溢价）** | BOM 与普通 TWS 接近 → 零售 $120–450 / ¥1500–2500 | 时空壶、科大讯飞翻译耳机 | 同传体验是壁垒，可卖时长包 / 离线包 |
| **品牌 TWS + AI 卖点** | 在成熟声学 SKU 上叠翻译 / 助手 | 华为 FreeBuds、三星 Galaxy Buds、Apple AirPods 等 | AI 激活率不一定高，主要服务溢价与差异化 |
| **白牌走量** | BOM 极低 → 零售 99–299 元 | 深圳供应链跨境电商 | 「带翻译」作卖点，云端成本必须严格封顶 |

对方案商 / 品牌商的含义：

- **没有同传体验壁垒** → 不要跟垂类抢 $300+ 档；走品牌声学 + 轻量 AI 或白牌封顶云端
- **有双语同传 / 双端对讲工程能力** → 才有资格走翻译垂类溢价
- **不要用玩具的「走量 +40 元」模型硬套旗舰同传**：同传用户日活时长更高，云端必须单独算账

### 1.2 当前阶段：硬件溢价为主，时长包为辅

公开市场观察：

```
翻译垂类：
  硬件一次性溢价（主收入）
  + 离线语言包 / 年费时长包（辅，部分品牌已披露）

对话 / 助手向：
  多数仍把云端成本摊进硬件
  「聊天月费」心智弱于翻译时长包
```

### 1.3 下一阶段：通话翻译与会议复盘才是黏性

| 能力 | 作用 | 现状 |
|---|---|---|
| **面对面双向同传** | 各戴一耳 / 一副，无按键对话 | 垂类标配；时空壶 WT2 Edge、讯飞 AI 翻译耳机均公开主打 |
| **通话 / 线上会议翻译** | 电话、视频会议实时双语 | 高客单差异化；讯飞公开宣称通话同传 |
| **会后转写与纪要** | 原生 + 译文落盘 | 与录音卡重叠；耳机侧常做轻量版，重纪要走 [`07`](../07-recorder/) |
| **音色克隆播报** | 用己方音色播译文 | 讯飞公开宣称音色相似度卖点；合规与授权须评估 |

**逻辑链**：同传体验保底线 → 通话 / 会议场景做刚需 → 才可能谈时长订阅。纯「AI 闲聊耳机」推月费，公开市场证据弱于翻译时长包。

## 二、形态与客户画像

### 2.1 三种形态

| 形态 | 典型客单参考（公开） | 关键卖点 |
|---|---|---|
| 入耳式同传（双耳分戴 / 同戴） | Timekettle M3 约 $120–150；WT2 Edge 约 $280–350 | 双向同传、离线包 |
| 开放式 / 耳挂翻译旗舰 | 讯飞 AI 翻译耳机约 ¥2499 | 骨导+气导拾音、通话同传、专业词库 |
| 品牌 TWS + AI 功能 | 依品牌声学档位 | 音乐 / 通话为主，翻译为加分项 |

### 2.2 三类客户

| 类型 | 特征 | 适合路线 |
|---|---|---|
| 白牌 / ODM 蓝牙耳机厂 | 深圳供应链，量大利薄 | 封顶云端配额 + 三段式或轻量翻译 API |
| 出海品牌 | 亚马逊 / 线下渠道成熟 | 翻译垂类或「声学 + 翻译」双卖点 |
| 翻译垂类 / 教育外贸 | 强场景获客 | 高客单同传 + 离线 / 时长包 |

### 2.3 与录音卡、眼镜的边界

| 判断维度 | 走 AI 耳机（本品类） | 走录音卡 [`07`](../07-recorder/) | 走 AI 眼镜 [`02`](../02-ai-glasses/) |
|---|---|---|---|
| 主体验 | 佩戴听感 + 实时听译 / 对讲 | 录完出纪要 | 视觉问答 + 字幕 / 同传 |
| 输出 | 耳内音频为主，字幕在手机 | App / Web 结构化文档 | 屏显字幕 + 耳内 / 骨传导 |
| 订阅锚点 | 翻译时长 / 离线包 | SaaS 转写分钟数 | 硬件溢价 + 翻译包（探索期） |

## 三、订阅可行性：翻译时长已知部分跑通，对话月费偏弱

**结论（公开信息）**：

1. **翻译时长包 / 离线语言包** — 垂类品牌有公开产品形态（如 Timekettle 离线包 / FISH CARD 披露），属于「功能包」而非泛聊天月费，**相对可跑通**。
2. **AI 对话月费** — 公开市场少见独立跑通样板；多数摊进硬件或绑品牌生态会员。
3. **转写分钟数订阅** — 更像录音卡（Plaud 等），耳机侧若主打转写应对照 [`07-recorder/01-business.md`](../07-recorder/01-business.md)。

**建议**：

- 翻译垂类：硬件溢价为主，时长 / 离线包为辅；云端按「日均同传分钟 × 目录价」预提
- 对话向：默认三段式 flash/plus，Realtime 仅旗舰评估
- 架构预留「通话翻译会话」计量，便于日后包装年费

## 四、毛利结构（量级）

仅作行业一般性陈述，非任何具体厂商数据：

```
翻译垂类（零售约 2000 元档）示意：

  零售价：               2000 元
  - 渠道与营销：        400–700 元
  - 硬件 BOM + 组装：   150–400 元
  - 首年云端 AI 摊销：   50–200 元（强依赖日均同传分钟）
  - 认证 / 售后预提：    30–80 元
  ─────────────────────────────
  品牌侧毛利空间：      约数百元量级（强依赖渠道与激活率）
```

三个结论：

1. **同传云端可以吃掉毛利**——若用户日均 1 小时双向同传且无封顶，年费可轻松超过硬件毛利；必须做配额 / 时长包
2. 白牌 199 元档只能给「试用分钟 + 硬封顶」，不能承诺无限同传
3. 声学体验仍是复购口碑的一部分；纯 AI 不好听，退货率会反噬订阅

## 五、决策树：要不要做 AI 耳机

```
核心卖点是不是「跨语言沟通」？
  ├─ 是 → 走翻译垂类
  │        ├─ 有双端对讲 / 低延迟工程？ → 高客单同传（¥1500+ / $200+）
  │        └─ 没有 → 先做单向听译 + App 字幕，客单压在千元内
  └─ 否（助手 / 闲聊）
       ├─ 已有强声学品牌？ → 叠轻量 AI，云端摊进硬件
       └─ 没有 → 慎重；与白牌同质化严重，优先考虑录音卡或玩具陪伴赛道
```

## 六、品类适配速查

| 问题 | 建议 |
|---|---|
| 只要会后纪要 | 选 [`07-recorder`](../07-recorder/)，不要硬上耳机形态 |
| 要面对面双向同传 | 选本品类 + Livetranslate / 自研同传 |
| 要看菜单 / 招牌翻译 | 选 [`02-ai-glasses`](../02-ai-glasses/)，耳机可作音频外设 |
| 要全双工闲聊助手 | 三段式或 Omni-Realtime；客单需吃得下音频成本 |
