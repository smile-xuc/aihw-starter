## 二、云端 AI 成本测算

### 2.1 单次 Agent 调用量级

```
简单问答：     ~500 tokens
工具调用（FC）：~1500 tokens
复杂规划：     ~3000 tokens
```

计费页（目录价随官方调整）：https://help.aliyun.com/zh/model-studio/billing-of-model-studio

### 2.2 端云协同后的月费用（量级）

| 场景 | 单次费用量级 | 日均次数 | 月费用 / 台 |
|------|-------------:|---------:|------------:|
| 简单问答（多已分流到端） | ¥0.005 | 20 | ¥3.0 |
| 工具调用 | ¥0.015 | 10 | ¥4.5 |
| 复杂推理 / 规划 | ¥0.03 | 5 | ¥4.5 |
| **合计（典型用户）** | — | 35 | **约 ¥12** |

若**不做端侧分流**，同等活跃度月云费可上探到 ¥20–50；这是毛利杀手。

### 2.3 端侧 vs 云端成本权衡

| 维度 | 纯云端 | 端云协同 | 纯端侧 |
|------|--------|---------|--------|
| 硬件增量 | +¥0 | +¥80–150（NPU SoC） | +¥200–400 |
| 月云费用 / 台 | ¥20–50 | ¥8–15 | ¥0 |
| 万台年云费用 | ¥240–600 万 | ¥96–180 万 | ¥0 |
| 盈亏平衡观察 | 出货 <1k | 1k–50k | >50k |

**结论**：

1. 出货 <1000：纯云端最经济，快速验证
2. 1000–50000：端云协同最优
3. >50000：考虑更深端侧或纯本地

### 2.4 BYOK 的影响

部分产品（公开报道中 Rabbit 进阶 DLAM 等）改为用户自带 API Key：厂商云费下降，但「开箱即用」变弱，客服成本上升。适合极客向 SKU，不适合渠道礼品款。

## 四、成本结构概览

```
┌─────────────────────────────────────────┐
│  硬件 BOM + 贴片     35–50%             │
│  组装测试            8–12%              │
│  包装物流            5–10%              │
│  渠道营销            15–25%             │
│  云端 AI（2 年摊）   5–15%（分流后可控） │
└─────────────────────────────────────────┘
```

**结论**：Agent 硬件毛利敏感点在**渠道 + 云费失控**，不在单次 token 目录价。技术侧把 60–80% 高频意图留端，即可把云端占比压回可吸收区间。
