# 小智（XiaoZhi）开源方案 — 占位版

> [小智 AI 聊天机器人](https://github.com/78/xiaozhi-esp32) 是社区活跃的开源 AI 硬件项目，以 ESP32 + 端云结合的语音对话栈著称。本页是占位骨架，欢迎补充。

## 1. 能力地图（占位）

| 能力 | 在小智项目中的位置 | 备注 |
|---|---|---|
| 端侧唤醒 | ESP32 固件 + Wake Word | 需要补充：典型功耗 / 唤醒词训练流程 |
| 实时对话编排 | xiaozhi-server / xiaozhi-esp32 | 兼容多家大模型 |
| TTS / ASR 路由 | 配置层 | 可对接 Qwen / OpenAI / 火山 / Edge TTS 等 |
| 自定义角色 | 服务端 prompt | 适合玩具 / 陪伴 / 桌宠场景 |
| 多设备会话 | 待补充 | 群组化对话能力 |

## 2. 品类适配（占位）

| 品类 | 适配度 | 备注 |
|---|:-:|---|
| 🧸 [AI 玩具 / 陪伴](../by-category/03-toys-companion/) | ⭐⭐⭐⭐⭐ | 开源生态最活跃的方向 |
| 🪴 [桌宠](../by-category/04-desktop-pet/) | ⭐⭐⭐⭐ | ESP32 + 屏幕 / 舵机典型组合 |

## 3. 与千问方案的关系

小智项目本身**模型无关**，可以把后端模型路由到 [千问大模型方案](./01-qwen/README.md)。两者并非互斥：

```
小智 ESP32 端 ─┬─► 小智 server（路由）─┬─► 千问（百炼 / DashScope）
              │                       ├─► OpenAI
              │                       └─► 其他
              └─► 唤醒 / 音频前处理
```
