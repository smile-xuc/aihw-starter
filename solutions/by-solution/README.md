## 怎么读

每个方案页是**跨品类**的横切视图，回答三个问题：

1. **能力地图**：方案能力清单 / 价位 / SLA / 适合的场景
2. **品类适配**：在 6 个品类中分别如何落地（链接到 `solutions/0X-xxx/02-solution.md`）
3. **典型 BOM 与计费**：本方案接入后端云成本量级

- 想先选**赛道**：去 [按品类](../by-category/)
- 想先选**模型/框架**：留在本目录

## 贡献新方案

新增方案的步骤：

1. 在本目录新建 `0X-<方案名>.md`
2. 按"能力地图 → 品类适配 → BOM/计费"三块写
3. 在对应品类的 `solutions/0X-xxx/02-solution-<方案>.md` 中补充具体接入代码（可选）
4. 提 PR
