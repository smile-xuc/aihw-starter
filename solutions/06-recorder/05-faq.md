# 录音卡 / 会议盒子 常见问题（占位版）

> **占位说明**：本页只收录最高频的几个问题，详细 FAQ 待后续版本补充。
> 通用问题见根目录 [`faq.md`](../../faq.md)。

## A. 商业模式

**Q1：录音笔/会议盒子订阅能跑通吗？**
A：海外有跑通案例（Plaud Note 等），国内市场仍在探索期。订阅价值点是"转写时长包 + 高级摘要 + 多设备同步"，建议先做免费试用养习惯。

**Q2：硬件卖完就完事，还是必须做订阅？**
A：取决于产品定位。低 BOM（< 200 元）的卡片机/便携机适合"硬件低价 + 订阅高价"；高 BOM（> 800 元）的会议盒子可以走"硬件溢价 + 包年时长"。

## B. 技术架构

**Q3：本地 mp3 文件能直接传 Paraformer-v2 吗？**
A：不行，**Paraformer-v2 文件版只支持公网 URL**（OSS、HTTP/HTTPS）。SDK 不支持 oss:// 前缀，REST API 支持。bailian-cli 工具支持本地路径直传，会自动帮你上传 OSS。

**Q4：1 小时录音会自动切片吗？**
A：不需要手动切。Paraformer-v2 文件版直接支持长音频，内部自动处理。

**Q5：实时模式下纪要什么时候生成？**
A：实时 ASR 输出文字流，纪要 Agent 通常在录音结束后或定时触发（如每 5 分钟一次）做增量摘要。

**Q6：说话人分离的准确率怎么样？**
A：典型会议录音 2–5 个说话人场景下，速记可用。混叠严重或同性别语音相近会有混淆，建议提供说话人 voiceprint 注册做矫正。

## C. 隐私与合规

**Q7：如何保证录音内容不被云端留存？**
A：阿里云对话/转写 API 默认不留存数据，可在合同中约定。本地处理需求可考虑 fun-asr 开源版本私有化部署。

**Q8：会议中包含商业机密怎么办？**
A：① 选支持私有化部署的开源 ASR（fun-asr 等）；② 摘要也用本地 LLM；③ 完全离线方案目前仍受端侧算力限制。
