# Demo · 录音卡 / 会议盒子

> 本目录用于存放录音/纪要品类的可运行示例代码。
> 当前为占位版，欢迎社区贡献最小可运行 demo。

## 计划包含的 demo

- [ ] **`paraformer-file/`** — Paraformer-v2 文件转写 + 说话人分离完整流程
- [ ] **`fun-asr-realtime/`** — fun-asr 实时流式 + 说话人分离 demo
- [ ] **`map-reduce-summary/`** — 长会议 Map-Reduce 摘要（决策/待办/风险抽取）
- [ ] **`oss-upload/`** — OSS STS 临时凭证签名 URL 生成示例
- [ ] **`bailian-cli-asr/`** — bailian-cli 本地 mp3 一键转写
- [ ] **`meeting-card/`** — 纪要卡片 UI（Markdown / HTML 双版本）
