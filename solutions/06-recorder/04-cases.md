## 1. 海外参考

### 1.1 Plaud Note

公开渠道：[Plaud 官网](https://www.plaud.ai/)

- 卡片形态录音设备，2024 年北美爆款
- 接入 ChatGPT 做摘要，订阅模式月费 $7–24
- 代表"卡片设备 + AI 摘要订阅"路线

### 1.2 Limitless（前 Rewind） / Bee

公开渠道：[Limitless 官网](https://www.limitless.ai/) / [Bee 官网](https://www.bee.computer/)

- 可穿戴 AI 笔记设备
- 持续录音 + 隐私边界设计
- 商业模式仍在探索

### 1.3 Otter.ai / Fireflies.ai

- B 端会议纪要 SaaS 龙头
- 不卖硬件，但定义了"会议纪要订阅"产品形态
- 代表"软件订阅 + 高 ARPU"路线

## 2. 国内参考

### 2.1 讯飞智能录音笔系列

公开渠道：[讯飞商城](https://www.iflyrec.com/)

- 国内录音笔老牌厂商
- 硬件 + 转写时长包的销售模式

### 2.2 通义听悟（SaaS）

公开渠道：[通义听悟](https://tingwu.aliyun.com/)

- 阿里云端到端 SaaS，含 ASR + 说话人分离 + 纪要 Agent
- 可作为录音笔/会议盒子的"开箱即用后端"

### 2.3 钉钉 AI 听记

- 钉钉内置的会议纪要功能
- 代表"软件直接吃掉硬件"的趋势
