# 05 · AI 眼镜 常见问题（占位版）

> **占位说明**：本页只收录最高频的几个问题，详细 FAQ 待后续版本补充。
> 通用问题见根目录 [`faq.md`](../../faq.md)。

## A. 套件选型

**Q1：套件支持哪些芯片平台？**
A：官方未给出特定芯片白名单。SDK 提供 Linux / RTOS 版本，能跑标准 Linux 内核或主流 RTOS（FreeRTOS/AliOS Things 等）的硬件平台理论可接。具体接入指标视硬件而定，建议联系售前提供 demo 联调支持。

**Q2：套件 vs 裸调用，怎么选？**
A：
- 选**套件**：快速跑通端侧 demo、需要全双工对话、目标系统包含 Linux/RTOS、希望非工程师也能配置
- 选**裸调用**：已有成熟端侧框架、对协议有强定制需求、只需要单点能力（如只用 TTS）

**Q3：套件的全双工对话延迟多少？**
A：官方未给出量化 SLA。套件内置 VAD 与流式对话引擎，体感比"按住说话"模式自然。具体数值建议在客户实际硬件上做实测。

## B. 能力扩展

**Q4：能不能换成自己的 ASR/TTS？**
A：套件目前以打包能力为主。LLM 支持替换其他百炼大模型；ASR/TTS 是否可替换需要按具体协议看，复杂定制场景建议走裸调用。

**Q5：知识库怎么用？**
A：在控制台上传 PDF/Word/Markdown 文档，套件自动切片向量化。用户提问时套件先检索知识库，再把命中的片段送 LLM 生成回答。适合产品手册、说明书、领域知识等场景。

**Q6：套件的视觉能力有哪些？**
A：内置文物讲解、地标识别、花束搭配、药品识别、热量分析、绘本朗读等场景模板。底层调用 Qwen-VL 系列模型，可按业务场景定制 Prompt。

## C. 成本与计费

**Q7：套件 vs 裸调用，怎么算账？**
A：套件不额外收费，只按底层模型用量计费。如果产品规模小、研发资源有限，套件能省 1–3 个月研发周期；规模大（百万级 DAU）或需要深度定制的，可能拼裸 API 更可控。

**Q8：声音克隆能用吗？**
A：可以。套件 TTS 模块支持"一句话声音复刻"，调用方式与独立 CosyVoice 一致，参见 [`01-toys-companion/02-solution.md`](../01-toys-companion/02-solution.md) 中的克隆流程。

## D. 接入

**Q9：Demo 仓库在哪？怎么开始？**
A：[GitHub: aliyun/alibabacloud-bailian-speech-demo](https://github.com/aliyun/alibabacloud-bailian-speech-demo)。仓库内按 OS 分目录，每个目录有独立 README。建议先在 Linux 跑 demo 看完整链路。

**Q10：RTOS 平台有什么坑？**
A：① SDK 提供精简版本，内存占用与具体芯片平台有关；② WebSocket 协议要求设备支持 TLS；③ 建议先在 Linux 上跑通逻辑，再移植到 RTOS。
