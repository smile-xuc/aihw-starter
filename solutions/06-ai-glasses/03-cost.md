# 03 · AI 眼镜 成本与计费（占位版）

> **占位说明**：本品类成本测算为简版，详细数据将在后续版本补充。
> 完整接入方案请见 [`02-solution.md`](./02-solution.md)。

## 1. 多模态交互套件计费

| 项目 | 计费方式 | 备注 |
|---|---|---|
| LLM | 按 token | 默认 Qwen 系列，可换其他模型 |
| ASR | 按音频时长 | 套件已封装 |
| TTS | 按字符 | 套件已封装 |
| 视觉模型（Qwen-VL） | 按 token / 图片 | 调用 Qwen-VL 时计费 |
| 套件本身 | 当前不额外收费 | 仅按底层模型用量计费 |

## 2. 典型场景成本量级

### 2.1 拍照 + 物体识别场景

- 单次拍照 + Qwen-VL 识别：几分钱
- 日均 10–50 次：单台月成本 1–5 元

### 2.2 翻译眼镜

参考 [`04-ai-earphone/03-cost.md`](../04-ai-earphone/03-cost.md) 翻译耳机成本模型。

### 2.3 AR 字幕场景

- 持续字幕（看会议/视频）：1 小时 0.5–3 元
- 不建议全天候开启

## 3. BOM 与硬件成本（待补充）

AI 眼镜的硬件成本远高于云端 AI 成本：
- 光波导 / LCoS 模组（AR 形态）：数百到上千
- 摄像头模组（拍照形态）：几十到百
- 主控 SoC + 存储 + 电池：百级
- 眼镜框架 + 工艺设计：百级
