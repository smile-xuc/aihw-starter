# IPC（家用摄像头）

## 品类概述

- 家用 IP 摄像头 + AI大模型应用能力（视觉理解 + 视频内容检索 + 每日总结 + 自定义事件告警 + 一键成片）
- 形态：室内云台机、室外枪机、电池机，等
- 客单价：设备约50～500 元；叠加 云存储 / AI 服务订阅。

## 商业化现状（公开信息观察）

- **是 AI 硬件中订阅模式已知跑通的代表品类**：基于「100 段视频懒得自己看」的痛点，AI 摘要+语义检索+事件推送形成付费场景。
- **存量云存用户是最佳转化池**：已有付费习惯的用户对 AI 增值服务接受度高。
- **核心差异是「自然语言搜视频」**：摆脱按时间线翻找，改成「找昨晚 9 点小孩在沙发上跳的片段」。

## 成本与计费

- **BOM 增量**：零（只要摄像头能将图片/视频上传到 OSS 即可）
- **按量计费**：数据索引 + AI模型费用
- **报价口径**：月度订阅（已知跑通的市场范围 5–10 元/月，包年有折扣）
