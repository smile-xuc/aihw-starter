## 项目卡片格式

每个项目建议包含：

```
### 项目名

- **仓库**：GitHub URL
- **Star**：当前 Star 数
- **License**：MIT / Apache / GPL 等
- **框架**：ESP-IDF / Arduino / RPi 等
- **状态**：活跃 / 维护中 / 归档
- **简介**：一句话说明项目用途
- **关键特性**：列 3–5 条核心能力
- **依赖模型**：（可选）千问大模型 / OpenAI / 多模型可选
```
