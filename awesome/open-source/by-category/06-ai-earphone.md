# 开源项目 · AI 耳机方向

> 本页收录 AI 耳机、同传与近耳可穿戴相关开源项目（开源整机偏少，允许含音频栈与翻译 App）。
> 完整索引见 [`../ai-hardware-projects.html`](../ai-hardware-projects.html)。
> 对应方案：[`solutions/by-category/06-ai-earphone/`](../../../solutions/by-category/06-ai-earphone/)

## 推荐参考项目

### RTranslator

- **仓库**：https://github.com/niedev/RTranslator
- **Star**：以 HTML 大盘为准
- **License**：Apache-2.0
- **框架**：Android（可配合蓝牙耳机）
- **状态**：活跃
- **简介**：开源实时翻译应用，常作为「同传耳机」软件侧参考。
- **关键特性**：实时翻译；离线/在线模式；耳机场景友好
- **形态**：翻译 App（非耳机硬件整机）
- **HTML 品类**：翻译设备

### OpenEarable

- **仓库**：https://github.com/OpenEarable/open-earable
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：自定义 PCB + BLE + IMU
- **状态**：活跃
- **简介**：开源 AI 感知耳机平台，偏传感/活动识别而非大模型对话。
- **关键特性**：AI 活动识别；健康监测；手势检测
- **HTML 品类**：可穿戴 AI

### esp-adf（Espressif）

- **仓库**：https://github.com/espressif/esp-adf
- **Star**：以 HTML 大盘为准
- **License**：待核
- **框架**：ESP32 / ESP32-S3
- **状态**：活跃
- **简介**：乐鑫官方音频开发框架，耳机/近耳设备音频流水线参考。
- **关键特性**：音频流水线；语音唤醒；ASR；蓝牙音频
- **形态**：音频栈（非成品耳机）
- **HTML 品类**：语音 AI

### OpenPin

- **仓库**：https://github.com/MaxMaeder/OpenPin
- **Star**：以 HTML 大盘为准
- **License**：待核
- **框架**：Humane AI Pin
- **状态**：维护中
- **简介**：让 Humane AI Pin 重新可用的开源项目；近身可穿戴交互可参考。
- **关键特性**：自定义软件；AI Pin 复活
- **HTML 品类**：可穿戴 AI

### Pi Pin

- **仓库**：https://github.com/liltom-eth/pi-pin
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：Raspberry Pi
- **状态**：维护中
- **简介**：基于树莓派的开源 AI Pin，全天佩戴向参考（非入耳，近身形态）。
- **关键特性**：全天佩戴；AI 助手
- **HTML 品类**：可穿戴 AI

### Omi（另见）

- **仓库**：https://github.com/BasedHardware/omi
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **简介**：开源 AI 可穿戴录音转写。**主卡在** [`07-recorder.md`](./07-recorder.md)；耳机场景仅作交叉参考。
- **HTML 品类**：语音 AI
