## 推荐参考项目

### Frigate NVR

- **仓库**：https://github.com/blakeblackshear/frigate
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：x86/ARM + Coral TPU
- **状态**：活跃
- **简介**：本地 NVR + 实时 AI 物体检测，家庭/小微 IPC 场景的主流开源栈。
- **关键特性**：实时目标检测；人/车/动物追踪；事件录制
- **HTML 品类**：视觉 AI

### jetson-inference

- **仓库**：https://github.com/dusty-nv/jetson-inference
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：NVIDIA Jetson Nano/Xavier/Orin
- **状态**：活跃
- **简介**：NVIDIA Jetson「Hello AI World」推理部署指南与示例，适合边缘视觉入门。
- **关键特性**：图像分类；目标检测；语义分割；姿态估计
- **HTML 品类**：视觉 AI

### AI-on-the-edge-device

- **仓库**：https://github.com/jomjol/AI-on-the-edge-device
- **Star**：以 HTML 大盘为准
- **License**：待核
- **框架**：ESP32-CAM / ESP32-S3
- **状态**：活跃
- **简介**：用 ESP32 摄像头 + 端侧神经网络数字化模拟仪表读数。
- **关键特性**：CNN 数字识别；TFLite 端侧推理；仪表读数
- **HTML 品类**：视觉 AI

### OpenALPR

- **仓库**：https://github.com/openalpr/openalpr
- **Star**：以 HTML 大盘为准
- **License**：AGPL-3.0
- **框架**：Linux/Windows + 摄像头
- **状态**：维护中
- **简介**：自动车牌识别库，IPC/车场视觉的经典开源参考。
- **关键特性**：车牌检测；OCR；多地区格式
- **HTML 品类**：视觉 AI

### openpilot（comma.ai）

- **仓库**：https://github.com/commaai/openpilot
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：comma 3X（Snapdragon）
- **状态**：活跃
- **简介**：开源 ADAS / 驾驶视觉操作系统。**边界**：作「驾驶视觉参考」，非家用 IPC 产品形态。
- **关键特性**：车道/前车检测；驾驶员监控；端到端神经网络
- **HTML 品类**：视觉 AI

### ZoneMinder

- **仓库**：https://github.com/ZoneMinder/zoneminder
- **Star**：以 HTML 大盘为准
- **License**：GPL-2.0
- **框架**：x86 Linux
- **状态**：活跃
- **简介**：成熟的开源 CCTV / NVR 系统，可与 AI 检测插件组合。

- **HTML 品类**：视觉 AI

### DeepCamera（SharpAI）

- **仓库**：https://github.com/SharpAI/DeepCamera
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：RPi / Jetson / x86
- **状态**：活跃

- **关键特性**：人脸识别；行人重识别；Qwen VLM 分析
- **HTML 品类**：视觉 AI
