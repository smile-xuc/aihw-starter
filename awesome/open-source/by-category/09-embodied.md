## 推荐参考项目

### LeRobot（Hugging Face）

- **仓库**：https://github.com/huggingface/lerobot
- **Star**：以 HTML 大盘为准
- **License**：Apache-2.0
- **框架**：硬件无关（支持 SO-100 等）
- **状态**：活跃
- **简介**：让 Robotics AI 更可及的端到端学习框架。
- **关键特性**：模仿学习；强化学习；预训练策略；Sim-to-Real
- **HTML 品类**：机器人

### SO-ARM100 / SO-101

- **仓库**：https://github.com/TheRobotStudio/SO-ARM100
- **Star**：以 HTML 大盘为准
- **License**：Apache-2.0
- **框架**：3D 打印 + STS3215 舵机
- **状态**：活跃
- **简介**：低成本标准开源机械臂，常与 LeRobot 联用。
- **关键特性**：模仿学习；遥操作；AI 策略训练
- **HTML 品类**：机器人

### OpenCat（Petoi）

- **仓库**：https://github.com/PetoiCamp/OpenCat-Quadruped-Robot
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：Arduino/ESP32 + RPi
- **状态**：活跃
- **简介**：开源四足机器人框架，步态与视觉/语音可扩展。
- **关键特性**：AI 步态；语音控制；计算机视觉；强化学习
- **HTML 品类**：机器人

### JetBot（NVIDIA）

- **仓库**：https://github.com/NVIDIA-AI-IOT/jetbot
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：Jetson Nano
- **状态**：维护中
- **简介**：NVIDIA 开源 AI 机器人平台，入门级具身视觉导航参考。
- **关键特性**：碰撞规避；跟随；路标跟随
- **HTML 品类**：机器人

### Reachy Mini（Pollen）

- **仓库**：https://github.com/pollen-robotics/reachy_mini
- **Star**：以 HTML 大盘为准
- **License**：Apache-2.0
- **框架**：Pollen Reachy 生态
- **状态**：活跃
- **简介**：开源桌面/小型人形向机械臂机器人参考。
- **关键特性**：开源硬件；遥操作；AI 扩展
- **HTML 品类**：机器人

### OpenArm

- **仓库**：https://github.com/enactic/openarm
- **Star**：以 HTML 大盘为准
- **License**：Apache-2.0
- **框架**：开源机械臂
- **状态**：活跃
- **简介**：开源机械臂项目，面向学习与二次开发。
- **关键特性**：开源硬件；控制栈；可扩展
- **HTML 品类**：机器人
