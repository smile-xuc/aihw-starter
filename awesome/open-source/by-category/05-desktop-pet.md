## 推荐参考项目

### AIRI（赛博伴侣）

- **仓库**：https://github.com/moeru-ai/airi
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：PC / 桌面
- **状态**：活跃
- **简介**：开源 AI 伴侣/虚拟角色容器，桌面陪伴与多模态交互参考。
- **关键特性**：实时语音；游戏交互；VRM/Live2D；多模态
- **HTML 品类**：机器人

### ElectronBot（稚晖君）

- **仓库**：https://github.com/peng-zhihui/ElectronBot
- **Star**：以 HTML 大盘为准
- **License**：GPL-3.0
- **框架**：STM32 + USB 屏
- **状态**：维护中
- **简介**：桌面级小机器工具人，表情屏 + 自由度结构，经典桌宠硬件参考。
- **关键特性**：USB 表情显示；6 自由度；AI 扩展
- **HTML 品类**：机器人

### Dummy-Robot（稚晖君）

- **仓库**：https://github.com/peng-zhihui/Dummy-Robot
- **Star**：以 HTML 大盘为准
- **License**：待核
- **框架**：自研驱动板
- **状态**：维护中
- **简介**：超迷你机械臂；桌面展示向，也可作具身入门（另见 09）。
- **关键特性**：智能机械臂控制；视觉辅助；精密运动
- **HTML 品类**：机器人
- **另见**：[`09-embodied.md`](./09-embodied.md)

### MagicMirror

- **仓库**：https://github.com/MagicMirrorOrg/MagicMirror
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：Raspberry Pi / Node.js
- **状态**：活跃
- **简介**：开源魔镜平台。**形态说明**：桌面/墙面显示站，非毛绒桌宠，但对「桌面 AI 信息面」可参考。
- **关键特性**：模块化插件；本地隐私；信息仪表盘
- **HTML 品类**：显示创意

- **关键特性**：桌面形态；轻量交互；AI 助手联动
- **HTML 品类**：机器人
