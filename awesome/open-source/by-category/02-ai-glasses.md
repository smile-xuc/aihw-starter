## 推荐参考项目

### OpenGlass

- **仓库**：https://github.com/BasedHardware/OpenGlass
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：XIAO ESP32-S3 + 摄像头
- **状态**：活跃
- **简介**：用低成本配件把普通眼镜改造成 AI 智能眼镜。
- **关键特性**：实时物体识别；对话转写；视觉 AI 查询
- **HTML 品类**：可穿戴 AI

### OpenSourceSmartGlasses（Mentra）

- **仓库**：https://github.com/Mentra-Community/OpenSourceSmartGlasses
- **Star**：以 HTML 大盘为准
- **License**：待核
- **框架**：ESP32 + 摄像头 + 麦克风
- **状态**：活跃
- **简介**：面向全天佩戴的开源智能眼镜硬件/软件参考。
- **关键特性**：AI AR 显示；语音命令；视觉辅助；App 生态
- **HTML 品类**：可穿戴 AI

### MentraOS

- **仓库**：https://github.com/Mentra-Community/MentraOS
- **Star**：以 HTML 大盘为准（2026-09 核验；HTML 大盘可能未单独收录）
- **License**：Apache-2.0
- **框架**：智能眼镜 OS（跨硬件）
- **状态**：活跃
- **简介**：Mentra 社区智能眼镜操作系统，支持字幕、视角流等能力。
- **关键特性**：实时字幕；视角流；眼镜 App 运行时
- **HTML 品类**：—（外链补录，已核验）

### ADeus

- **仓库**：https://github.com/adamcohenhillel/ADeus
- **Star**：以 HTML 大盘为准
- **License**：待核
- **框架**：Coral AI + Raspberry Pi
- **状态**：活跃
- **简介**：开源 AI 可穿戴（偏音频记忆）；眼镜方案常与其架构对照参考。
- **关键特性**：持续音频捕获；自托管转写；个性化 AI
- **HTML 品类**：可穿戴 AI

### OpenAIglasses_for_Navigation

- **仓库**：https://github.com/AI-FanGe/OpenAIglasses_for_Navigation
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：ESP32-CAM
- **状态**：活跃
- **简介**：AI 智能眼镜辅助盲人导航，YOLO 目标检测 + 语音交互。
- **关键特性**：YOLO 检测；盲道导航；物体识别；语音交互
- **HTML 品类**：视觉 AI

### OpenBCI GUI

- **仓库**：https://github.com/OpenBCI/OpenBCI_GUI
- **Star**：以 HTML 大盘为准
- **License**：MIT
- **框架**：OpenBCI Cyton/Ganglion
- **状态**：活跃
- **简介**：开源脑机接口平台（非眼镜整机）；可作为头戴/感知融合的旁路参考。
