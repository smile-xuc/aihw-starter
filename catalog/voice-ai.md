## 📌 选型建议

- **2 小时跑通入门款** → xiaozhi-esp32 + xiaozhi-esp32-server（中文社区资源最全）
- **想做产品级语音助手** → esp-box（乐鑫官方背书）/ Willow（离线本地）
- **想做 AI 眼镜/项链** → Omi / OpenGlass / MentraOS
- **极客玩家/家居集成** → Home LLM + Home Assistant Voice PE
- **桌宠/AI 玩具方向** → ElatoAI / Starmoon / DAZI-AI
